Bài 13 — INSERT, UPDATE & DELETE: thay đổi dữ liệu

Đến giờ bạn chỉ đọc dữ liệu. Nhưng dữ liệu thật luôn thay đổi: khách mới đăng ký, giá được cập nhật, sản phẩm ngừng bán. Ba câu lệnh lo việc đó là INSERT (thêm dòng), UPDATE (sửa dòng), DELETE (xóa dòng).

Khác với SELECT, ba lệnh này không trả về bảng kết quả — chúng lặng lẽ thay đổi dữ liệu. Vì vậy trong mỗi bài tập, bạn viết lệnh thay đổi rồi thêm một câu SELECT để xem kết quả và được chấm. Câu SELECT kiểm tra đã có sẵn ở khung soạn thảo — việc của bạn là thêm lệnh thay đổi phía trên nó.

Yên tâm: mỗi lần chạy, truy vấn thao tác trên một bản sao mới của cơ sở dữ liệu. Bạn có thể xóa, sửa thoải mái — dữ liệu gốc luôn được đặt lại cho bài tập tiếp theo.

1. INSERT — thêm dòng mới

Cách rõ ràng nhất là nêu tên cột rồi cho giá trị tương ứng:

INSERT INTO products (id, name, category, price, stock)
VALUES (11, 'Kẹo dẻo mềm', 'Đồ ăn', 15000, 100);

SELECT name, price FROM products WHERE id = 11;
Bài tập 1. Thêm sản phẩm (11, 'Kẹo dẻo mềm', 'Đồ ăn', 15000, 100) bằng INSERT INTO products (id, name, category, price, stock) VALUES (...). Câu SELECT bên dưới sẽ hiện kết quả.

Nếu cho giá trị cho tất cả các cột đúng thứ tự, có thể bỏ danh sách tên cột:

INSERT INTO products VALUES (12, 'Trà sữa trân châu', 'Đồ uống', 40000, 60);
Bài tập 2. Thêm sản phẩm (12, 'Trà sữa trân châu', 'Đồ uống', 40000, 60) bằng INSERT INTO products VALUES (...) (không cần liệt kê cột).
Bài tập 3. Thêm khách hàng (5, 'Vũ Thị E', 'Cần Thơ', '2025-08-01') vào bảng customers.

2. UPDATE — sửa dòng đã có

UPDATE bảng SET cột = giá_trị WHERE điều_kiện. Luôn nhớ WHERE — nếu quên, bạn sẽ sửa tất cả các dòng!

UPDATE products SET price = 6000 WHERE id = 1;

SELECT id, price FROM products WHERE id = 1;
Bài tập 4. Đổi giá của sản phẩm id = 1 thành 6000 bằng UPDATE products SET price = 6000 WHERE id = 1.
Bài tập 5. Tăng stock thêm 50 cho mọi hàng 'Điện tử': UPDATE products SET stock = stock + 50 WHERE category = 'Điện tử'.
Bài tập 6. Sửa hai cột cùng lúc cho sản phẩm id = 9: đặt price = 9000 và stock = 200 (các cột cách nhau dấu phẩy).

3. DELETE — xóa dòng

DELETE FROM bảng WHERE điều_kiện. Cũng như UPDATE, đừng bao giờ quên WHERE — không thì cả bảng sẽ trống.

DELETE FROM products WHERE id = 10;

SELECT COUNT(*) AS n FROM products;
Bài tập 7. Xóa sản phẩm id = 10 bằng DELETE FROM products WHERE id = 10. (Sau khi xóa còn 9 sản phẩm.)
Bài tập 8. Xóa tất cả hàng 'Điện tử': DELETE FROM products WHERE category = 'Điện tử'. (Còn lại 8.)
Bài tập 9. Xóa mọi sản phẩm có giá dưới 10000: DELETE FROM products WHERE price < 10000. (Còn lại 8.)

4. Kết hợp nhiều lệnh

Bạn có thể chạy nhiều lệnh liên tiếp, mỗi lệnh kết thúc bằng ;.

Bài tập 10. Thêm sản phẩm (11, 'Sản phẩm mới', 'Đồ ăn', 10000, 10), rồi đổi giá của nó thành 12000. (Viết cả hai lệnh trên dòng SELECT.)
Bài tập 11. 🔥 Nâng cao. Tăng giá mọi hàng 'Đồ uống' thêm 2000: UPDATE products SET price = price + 2000 WHERE category = 'Đồ uống'. Câu SELECT sẽ hiện danh sách đã sắp theo giá.

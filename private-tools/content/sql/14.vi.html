Bài 14 — CREATE TABLE & kiểu dữ liệu

Cho tới giờ các bảng products, customers… đã có sẵn. Nhưng khi xây một ứng dụng mới, chính bạn là người thiết kế bảng: đặt tên bảng, khai báo các cột và kiểu dữ liệu của chúng. Đó là việc của CREATE TABLE.

Ba kiểu dữ liệu cơ bản nhất trong SQLite: INTEGER (số nguyên), TEXT (chuỗi), và REAL (số thực, có phần thập phân). Bạn cũng có thể đặt ràng buộc: PRIMARY KEY (khóa chính, định danh duy nhất), NOT NULL (bắt buộc có giá trị), DEFAULT (giá trị mặc định).

Như bài trước, mỗi bài tập bạn tạo bảng, thêm dữ liệu, rồi SELECT để xem kết quả. Mỗi lần chạy dùng một cơ sở dữ liệu mới nên bạn cứ tạo bảng thoải mái.

1. CREATE TABLE — tạo bảng

Khai báo tên bảng, rồi trong ngoặc là danh sách tên_cột kiểu, cách nhau bằng dấu phẩy.

CREATE TABLE suppliers (id INTEGER, name TEXT);
INSERT INTO suppliers VALUES (1, 'Công ty A');

SELECT * FROM suppliers;
Bài tập 1. Tạo bảng suppliers (id INTEGER, name TEXT), thêm dòng (1, 'Công ty A'), rồi câu SELECT bên dưới sẽ hiện nó.

2. Kiểu dữ liệu: INTEGER, TEXT, REAL

REAL dùng cho số có phần thập phân (ví dụ cân nặng, tỉ lệ).

CREATE TABLE items (id INTEGER, name TEXT, weight REAL);
INSERT INTO items VALUES (1, 'Gạo', 5.5);

SELECT name, weight FROM items;
Bài tập 2. Tạo bảng items (id INTEGER, name TEXT, weight REAL), thêm (1, 'Gạo', 5.5).
Bài tập 3. Tạo bảng sales (id INTEGER, price REAL, qty INTEGER), thêm (1, 10.5, 3), rồi tính price * qty AS total.

3. PRIMARY KEY — khóa chính

PRIMARY KEY đánh dấu cột định danh duy nhất cho mỗi dòng (giống cột id ở các bảng bạn đã dùng).

CREATE TABLE tags (id INTEGER PRIMARY KEY, label TEXT);
INSERT INTO tags VALUES (1, 'new'), (2, 'sale');

SELECT COUNT(*) AS n FROM tags;
Bài tập 4. Tạo bảng tags (id INTEGER PRIMARY KEY, label TEXT), thêm hai dòng (1, 'new'), (2, 'sale').
Bài tập 5. Tạo bảng colors (id INTEGER, name TEXT), thêm ba dòng (1, 'red'), (2, 'green'), (3, 'blue'), rồi SELECT name ... ORDER BY id.

4. NOT NULL và DEFAULT

NOT NULL bắt buộc cột phải có giá trị. DEFAULT cung cấp giá trị mặc định khi bạn không nêu cột đó lúc INSERT.

CREATE TABLE tickets (id INTEGER, status TEXT DEFAULT 'open');
INSERT INTO tickets (id) VALUES (1);

SELECT status FROM tickets WHERE id = 1;
Bài tập 6. Tạo bảng staff (id INTEGER PRIMARY KEY, name TEXT NOT NULL), thêm (1, 'An').
Bài tập 7. Tạo bảng tickets (id INTEGER, status TEXT DEFAULT 'open'), thêm chỉ id: INSERT INTO tickets (id) VALUES (1). Cột status sẽ tự nhận 'open'.
Bài tập 8. Tạo bảng members (id INTEGER PRIMARY KEY, name TEXT NOT NULL, points INTEGER DEFAULT 0), thêm chỉ id và name (1, 'Minh'). Cột points mặc định 0.

5. Tạo bảng từ dữ liệu có sẵn

CREATE TABLE … AS SELECT … tạo bảng mới và đổ ngay kết quả một truy vấn vào. INSERT INTO … SELECT … thì chép dữ liệu vào bảng đã có.

CREATE TABLE cheap AS
  SELECT name, price FROM products WHERE price < 15000;

SELECT COUNT(*) AS n FROM cheap;
Bài tập 9. Tạo bảng cheap chứa name, price của sản phẩm giá dưới 15000: CREATE TABLE cheap AS SELECT name, price FROM products WHERE price < 15000.
Bài tập 10. Tạo bảng rỗng drinks (name TEXT, price INTEGER), rồi chép mọi hàng 'Đồ uống' vào bằng INSERT INTO drinks SELECT name, price FROM products WHERE category = 'Đồ uống'.

6. Ghép mọi thứ lại

Bài tập 11. 🔥 Nâng cao. Tạo bảng scores (student TEXT, score INTEGER), thêm ('A', 8), ('B', 6), ('C', 10), rồi tính ROUND(AVG(score), 1) AS avg_score và MAX(score) AS best.

🏠 Homework

Bốn bài làm ở nhà, tự động chấm ngay trên trang. Bài cuối là bài nâng cao.

Bài tập 1. Tạo bảng cities (id INTEGER, name TEXT), thêm (1, 'Hà Nội'), (2, 'Huế'), rồi SELECT name ... ORDER BY id.
Bài tập 2. Tạo bảng measures (id INTEGER, value REAL), thêm (1, 3.14).
Bài tập 3. Tạo bảng electronics chứa name, price của hàng 'Điện tử': CREATE TABLE electronics AS SELECT name, price FROM products WHERE category = 'Điện tử'.
Bài tập 4. 🔥 Nâng cao. Tạo bảng tasks (id INTEGER PRIMARY KEY, title TEXT NOT NULL, done INTEGER DEFAULT 0), thêm chỉ id và title (1, 'A'), (2, 'B'), rồi tính SUM(done) AS total_done và COUNT(*) AS n.

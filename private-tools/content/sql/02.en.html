Lesson 2 — WHERE: filter to the rows you need

In Lesson 1 you pulled columns out of a table. But real tables have thousands or millions of rows — you rarely want to see all of them. Real questions always come with a condition: "which products cost more than 30,000₫?", "which customers are in Hà Nội?", "which items are in the Đồ uống (drinks) category?".

The WHERE clause is your filter. It sits right after FROM and keeps only the rows that satisfy your condition. Every other row is dropped from the result — the underlying data never changes, you are simply asking a question.

In this lesson you'll compare numbers and text, combine conditions with AND/OR, and match text patterns with LIKE. You will use this skill in almost every query from here on.

1. The shape of WHERE

Add a WHERE condition line after FROM:

SELECT name, price
FROM products
WHERE category = 'Đồ uống';

SQL checks each row: if category equals 'Đồ uống' it stays, otherwise it is dropped. Text values must sit inside single quotes '...'.

4. Combining conditions: AND, OR

Join conditions with AND (both must be true) or OR (at least one is true).

SELECT name, price
FROM products
WHERE category = 'Đồ uống' AND price < 30000;

5. Ranges: BETWEEN and IN

BETWEEN a AND b selects values in a range, inclusive of both ends. IN (…) matches any value in a list — much tidier than a long chain of OR.

SELECT name, price FROM products
WHERE price BETWEEN 10000 AND 30000;

SELECT name, category FROM products
WHERE category IN ('Đồ ăn', 'Điện tử');

6. Pattern matching: LIKE

When you only remember part of a name, use LIKE with wildcards: % stands for any string (including empty), _ stands for exactly one character.

PatternMatches
'S%'starts with S
'%đá'ends with đá
'%cam%'contains "cam" anywhere
SELECT name FROM products
WHERE name LIKE 'S%';

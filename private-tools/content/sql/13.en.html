Lesson 13 — INSERT, UPDATE & DELETE: changing data

So far you've only read data. But real data is always changing: new customers sign up, prices get updated, products are discontinued. The three statements for that are INSERT (add rows), UPDATE (change rows), and DELETE (remove rows).

Unlike SELECT, these three don't return a result table — they quietly change the data. So in each exercise you write the change and then add a SELECT to see the result and get graded. The checking SELECT is already in the editor — your job is to add the change statement above it.

Don't worry: every time you run, the query works on a fresh copy of the database. Delete and edit freely — the original data is reset for the next exercise.

1. INSERT — add a new row

The clearest way is to name the columns then give matching values:

INSERT INTO products (id, name, category, price, stock)
VALUES (11, 'Kẹo dẻo mềm', 'Đồ ăn', 15000, 100);

SELECT name, price FROM products WHERE id = 11;
Exercise 1. Add the product (11, 'Kẹo dẻo mềm', 'Đồ ăn', 15000, 100) with INSERT INTO products (id, name, category, price, stock) VALUES (...). The SELECT below shows the result.

If you provide values for all columns in order, you can drop the column list:

INSERT INTO products VALUES (12, 'Trà sữa trân châu', 'Đồ uống', 40000, 60);
Exercise 2. Add the product (12, 'Trà sữa trân châu', 'Đồ uống', 40000, 60) with INSERT INTO products VALUES (...) (no column list).
Exercise 3. Add the customer (5, 'Vũ Thị E', 'Cần Thơ', '2025-08-01') to the customers table.

2. UPDATE — change existing rows

UPDATE table SET column = value WHERE condition. Always remember the WHERE — forget it and you change every row!

UPDATE products SET price = 6000 WHERE id = 1;

SELECT id, price FROM products WHERE id = 1;
Exercise 4. Change the price of product id = 1 to 6000 with UPDATE products SET price = 6000 WHERE id = 1.
Exercise 5. Increase stock by 50 for all 'Điện tử' items: UPDATE products SET stock = stock + 50 WHERE category = 'Điện tử'.
Exercise 6. Change two columns at once for product id = 9: set price = 9000 and stock = 200 (columns separated by a comma).

3. DELETE — remove rows

DELETE FROM table WHERE condition. As with UPDATE, never forget the WHERE — otherwise the whole table is emptied.

DELETE FROM products WHERE id = 10;

SELECT COUNT(*) AS n FROM products;
Exercise 7. Delete product id = 10 with DELETE FROM products WHERE id = 10. (9 products remain.)
Exercise 8. Delete all 'Điện tử' items: DELETE FROM products WHERE category = 'Điện tử'. (8 remain.)
Exercise 9. Delete every product with a price below 10000: DELETE FROM products WHERE price < 10000. (8 remain.)

4. Combining several statements

You can run several statements in a row, each ending with ;.

Exercise 10. Add the product (11, 'Sản phẩm mới', 'Đồ ăn', 10000, 10), then change its price to 12000. (Write both statements above the SELECT.)
Exercise 11. 🔥 Stretch. Raise the price of all 'Đồ uống' items by 2000: UPDATE products SET price = price + 2000 WHERE category = 'Đồ uống'. The SELECT shows the list sorted by price.

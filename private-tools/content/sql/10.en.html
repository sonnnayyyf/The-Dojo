Lesson 10 — Subqueries

Sometimes, to answer one question you first need the result of another question. "Which products are above the average price?" — to know that, you first have to compute the average. "Which customer has never ordered?" — you need the list of customers who did order, to exclude them.

A subquery is a SELECT nested inside another SELECT, wrapped in parentheses ( … ). SQL runs the subquery first, takes its result, then uses it in the outer query.

Two kinds show up most: a subquery that returns a single value (for comparison, like > (SELECT AVG(...))), and one that returns a list (used with IN / NOT IN).

1. A subquery returning one value

An aggregate SELECT (like AVG, MAX) returns exactly one number. Put it in parentheses and compare directly.

SELECT name, price
FROM products
WHERE price > (SELECT AVG(price) FROM products)
ORDER BY price;
Exercise 1. Products priced above average: show name, price, filter price > (SELECT AVG(price) FROM products), sorted by price.
Exercise 2. Products priced below average: show name, price, filter price < (SELECT AVG(price) FROM products), sorted by price.

2. Comparing to a value filtered from a group

The subquery can have its own WHERE. For example: "cheaper than the priciest drink".

SELECT name, price
FROM products
WHERE price < (SELECT MAX(price) FROM products WHERE category = 'Đồ uống')
ORDER BY price;
Exercise 3. Products cheaper than the priciest 'Đồ uống' item: show name, price, filter price < (SELECT MAX(price) FROM products WHERE category = 'Đồ uống'), sorted by price.
Exercise 4. Products more expensive than 'Cà phê đen đá': show name, price, filter price > (SELECT price FROM products WHERE name = 'Cà phê đen đá'), sorted by price.

3. A subquery returning a list: IN

If the subquery returns many rows of one column, use IN to test "is it in this list?".

SELECT name
FROM products
WHERE id IN (SELECT product_id FROM order_items)
ORDER BY id;
Exercise 5. Products that have been sold: show name, filter id IN (SELECT product_id FROM order_items), sorted by id.
Exercise 6. Customers who have ordered: show name, filter id IN (SELECT customer_id FROM orders), sorted by id.

4. NOT IN — the ones not in the list

Flip it to NOT IN to find "the ones missing" — another way (besides LEFT JOIN from Lesson 9) to find inactive customers/products.

Exercise 7. Products that have never sold: show name, filter id NOT IN (SELECT product_id FROM order_items), sorted by id.
Exercise 8. Customers who have never ordered: show name, filter id NOT IN (SELECT customer_id FROM orders), sorted by id.

5. A subquery inside SELECT

You can also drop a precomputed value onto every row for easy comparison — e.g. showing the average price next to each product.

Exercise 9. For each product, show name, price, and the store-wide average price in an avg_all column: (SELECT ROUND(AVG(price)) FROM products) AS avg_all. Sort by id.

6. Nesting subqueries

A subquery can contain another subquery. "Products that customer 1 bought" = products found in the line items of customer 1's orders.

Exercise 10. Products that customer 1 bought: show name, filter id IN (SELECT product_id FROM order_items WHERE order_id IN (SELECT id FROM orders WHERE customer_id = 1)), sorted by id.

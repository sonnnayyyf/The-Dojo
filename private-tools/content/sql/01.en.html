Lesson 1 — SELECT & WHERE: query and filter data

A database is simply a set of tables — exactly like an Excel spreadsheet: each table has columns and rows. SQL is the language you use to ask questions of those tables and get answers back. Nothing to install: below is a real database for a small shop, running right in your browser.

This lesson covers the two most important things when reading data: SELECT to choose which columns, from which table, and WHERE to filter the exact rows you need. Almost every query you write later starts with these two.

Take it slow. Every "▶ Try it" box is a real editor: type a query, run it, see the result, and get graded instantly. Getting it wrong is fine — just try again.

2. The shape of a query

A basic SELECT has two parts: choose the columns, and name the table.

SELECT name, price
FROM products;

Read it as: "SELECT the columns name, price FROM the products table". The ; ends the statement. SQL is not case-sensitive, but a good habit is to write keywords in UPPERCASE (SELECT, FROM, WHERE) so they stand out.

3. SELECT * — every column

The * means "all columns". Handy for a quick peek at what a table contains.

SELECT * FROM products;
Exercise 1. Show all columns of every product in the products table.

4. Choosing just the columns you need

In practice you rarely want everything. Name exactly the columns you want, separated by commas. They appear in the order you write them.

SELECT price, name FROM products;

5. Working with the other tables

SELECT works on any table — just change the name after FROM.

SELECT * FROM customers;
Exercise 4. Show all columns of every customer in the customers table.

6. WHERE — filter to the rows you need

Real tables have thousands of rows — you rarely want them all. The WHERE clause sits after FROM and keeps only the rows that satisfy your condition. Text values must sit inside single quotes '...'.

SELECT name, price
FROM products
WHERE category = 'Đồ uống';
Exercise 5. Show all columns of every product in the 'Đồ uống' category.

7. Comparison operators

For numbers you have the full set of comparisons: = (equal), <> (not equal), > < (greater/less than), >= <=.

SELECT name, price
FROM products
WHERE price > 30000;

8. Combining conditions: AND, OR

Join conditions with AND (both must be true) or OR (at least one is true).

SELECT name, price
FROM products
WHERE category = 'Đồ uống' AND price < 30000;
Exercise 10. Get name, price of products in the 'Đồ uống' category and priced below 30000.

9. Ranges: BETWEEN and IN

BETWEEN a AND b selects values in a range, inclusive of both ends. IN (…) matches any value in a list — much tidier than a long chain of OR.

SELECT name, price FROM products
WHERE price BETWEEN 10000 AND 30000;

SELECT name, category FROM products
WHERE category IN ('Đồ ăn', 'Điện tử');
Exercise 12. Get name, price of products priced from 10000 to 30000 (use BETWEEN).
Exercise 13. Get name, category of products in the 'Đồ ăn' or 'Điện tử' category (use IN).

10. Pattern matching: LIKE

When you only remember part of a name, use LIKE with wildcards: % stands for any string, _ for exactly one character. E.g. 'S%' = starts with S, '%cam%' = contains "cam".

SELECT name FROM products
WHERE name LIKE 'S%';

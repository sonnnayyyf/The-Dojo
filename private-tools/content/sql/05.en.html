Lesson 5 — Aggregates: COUNT, SUM, AVG, MIN, MAX

Every query so far returned individual rows. But a manager rarely asks "list all 10,000 orders" — they ask for one number: "how many products do we have?", "what's the total stock?", "the average price?", "how much does the most expensive item cost?".

That's the job of aggregate functions. They collapse many rows into a single value: COUNT counts, SUM adds, AVG averages, MIN/MAX find the smallest/largest.

Combined with WHERE, you compute a number for exactly the group you care about. This is the foundation of every report — and in Lesson 6 you'll learn GROUP BY to compute these numbers for each group at once.

1. COUNT — count rows

COUNT(*) counts the rows that match the query. Always name the column with AS.

SELECT COUNT(*) AS total
FROM products;

2. Counting distinct values: COUNT(DISTINCT …)

To find out how many different values exist, use COUNT(DISTINCT column) — it ignores duplicates.

SELECT COUNT(DISTINCT category) AS categories
FROM products;
Exercise 3. Count the number of distinct categories (category) in products, naming the column categories.

3. SUM — add it all up

SUM(column) adds every value in a numeric column.

SELECT SUM(stock) AS total_stock
FROM products;
Exercise 4. Compute the total stock (SUM(stock)) across all products, naming the column total_stock.

4. AVG — the average

AVG(column) computes the mean. The result is usually fractional, so it's common to wrap it in ROUND(…).

SELECT AVG(price) AS avg_price
FROM products;

SELECT ROUND(AVG(price)) AS avg_price
FROM products
WHERE category = 'Đồ uống';

5. MIN and MAX

MIN finds the smallest value, MAX the largest — they work on numbers, text, and dates.

SELECT MIN(price) AS cheapest, MAX(price) AS most_expensive
FROM products;

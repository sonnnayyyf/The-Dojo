Lesson 6 — CASE WHEN: conditional logic in queries

Raw data isn't always in the shape you need. A manager doesn't want to see 350000 — they want the label "premium". A low stock value needs flagging as "reorder". This is where CASE WHEN comes in — it's SQL's "if/else".

CASE WHEN looks at each row and returns a value depending on a condition. You can use it in SELECT (to build a new column), in ORDER BY (to sort by a label), and even inside an aggregate to count/sum conditionally — a very powerful reporting trick.

Every column you create here should get an AS alias for a clear name — as you learned in Lesson 3.

1. CASE WHEN — labels by condition

Syntax: CASE WHEN condition THEN value ... ELSE default END. SQL checks the branches top to bottom and stops at the first true one.

SELECT name,
  CASE WHEN price >= 100000 THEN 'high'
       WHEN price >= 20000  THEN 'medium'
       ELSE 'low' END AS tier
FROM products;

3. CASE returning a number

CASE doesn't only return text — it can return numbers too, perfect for a conditional calculation.

SELECT name,
  ROUND(CASE WHEN category = 'Điện tử' THEN price * 0.85
             ELSE price * 0.95 END) AS final_price
FROM products;
Exercise 4. Compute final_price: 'Điện tử' items get 15% off (price * 0.85), everything else 5% off (price * 0.95), then ROUND. Show name and final_price.

7. Conditional counting and summing

Put CASE inside SUM to count or add only the rows that meet a condition — a very handy reporting trick: SUM(CASE WHEN … THEN 1 ELSE 0 END) counts matching rows.

SELECT SUM(CASE WHEN price >= 50000 THEN 1 ELSE 0 END) AS expensive_count
FROM products;

Lesson 3 — ORDER BY & LIMIT: sort and take the top

Query results so far came back in the table's "natural" order — nothing guarantees it means anything. But business questions almost always need an order: "the most expensive product?", "the newest customer?", "the 5 items with the most stock?".

ORDER BY sorts your results by one (or more) columns. Combine it with LIMIT to take just the first few rows and you have a tool for every "top N" question — which shows up in almost every real report.

ORDER BY always comes after WHERE (if present), and LIMIT comes last. Remember the order: SELECT … FROM … WHERE … ORDER BY … LIMIT ….

1. ORDER BY — ascending sort

By default ORDER BY column sorts ascending (small → large for numbers, A → Z for text):

SELECT name, price
FROM products
ORDER BY price;
Exercise 1. Get name, price of every product, sorted by price ascending.

2. Descending with DESC

Add DESC to reverse it — large → small. (The default direction is ASC, which you usually don't write.)

SELECT name, price
FROM products
ORDER BY price DESC;
Exercise 2. Get name, price of every product, sorted by price descending.

3. Sorting text and dates

ORDER BY also works on text (alphabetical order) and on dates stored as YYYY-MM-DD strings (thanks to that format, comparing the strings is the same as comparing the dates).

SELECT name FROM products
ORDER BY name;

4. Sorting by multiple columns

List several columns separated by commas. SQL sorts by the first; only when values tie does it look at the next column. Each column can have its own direction.

SELECT name, category, price
FROM products
ORDER BY category, price;
Exercise 5. Get name, category, price, sorted by category then by price (both ascending).

5. LIMIT — take only the first few rows

LIMIT n trims the result to at most n rows. Great for a quick peek, or combined with ORDER BY to grab the "top".

SELECT name FROM products
ORDER BY id
LIMIT 3;
Exercise 6. Get the name of the first 3 products by id (sort by id, limit to 3 rows).

6. The "top N" formula

Pairing ORDER BY … DESC with LIMIT n is the classic way to get "the n largest". Flip it to ASC for "the n smallest".

SELECT name, price
FROM products
ORDER BY price DESC
LIMIT 3;

7. Skipping rows: OFFSET

LIMIT n OFFSET k skips the first k rows then takes the next n — useful for paging, or for "2nd and 3rd place".

Lesson 3 — Calculations in SELECT & naming with AS

So far SELECT only pulls out values that already exist. But SQL can also calculate: multiply price by quantity for revenue, add VAT, take 10% off, glue text together into a readable label. No need to export to Excel — do it right in the query.

When you write an expression in SELECT, the result is a new column computed for every row. By default that column gets an ugly name (the expression itself), so we use AS to give it a tidy alias.

This lesson introduces four tools: arithmetic, string concatenation with ||, rounding with ROUND, and the AS alias. Together they turn raw columns into meaningful information.

1. Arithmetic

You have + - * / right inside SELECT. SQL computes it per row:

SELECT name, price * stock
FROM products;

To give the result column a nice name, add AS column_name:

SELECT name, price * stock AS inventory_value
FROM products;
Exercise 1. For each product, show name and the stock value price * stock, naming the column inventory_value.
Exercise 2. Show name and double the price (price * 2), naming the column double_price.

2. AS — naming columns

AS isn't only for expressions — you can rename an existing column to make a report easier to read.

SELECT name AS product_name, price AS vnd
FROM products;
Exercise 3. Show name renamed to product_name and price renamed to vnd.
Exercise 4. Show name and the price after a flat 3000₫ discount (price - 3000), naming the column discounted.

3. Joining text with ||

The || operator concatenates strings. Insert static characters (in quotes) to build a readable label.

SELECT name || ' (' || category || ')' AS label
FROM products;
Exercise 5. Build a label column in the form name (category) — e.g. Cà phê đen đá (Đồ uống). Use exactly name || ' (' || category || ')'.

4. Rounding with ROUND

Multiplying by a decimal (discounts, tax) produces fractional numbers. ROUND(expression) rounds to the nearest whole number.

SELECT name, ROUND(price * 0.9) AS sale_price
FROM products;
Exercise 6. Show name and the price after a 10% discount: ROUND(price * 0.9), naming the column sale_price.
Exercise 7. Show name and the price with 10% VAT added: ROUND(price * 1.1), naming the column price_with_vat.

5. Calculations combined with WHERE

You can filter and calculate at once. (Note: WHERE cannot use an AS alias — you must repeat the full expression in WHERE.)

SELECT name, ROUND(price * 0.8) AS sale_price
FROM products
WHERE category = 'Đồ uống';
Exercise 8. For the 'Đồ uống' category only: show name and the price at a 20% discount (ROUND(price * 0.8)), naming the column sale_price.
Exercise 9. Only products with a stock value of 1,000,000 or more: show name and price * stock AS inventory_value. Use the expression price * stock in WHERE.

6. Sorting by a calculated value

ORDER BY also works on a computed expression — perfect for finding the "top" by a metric you invent.

Exercise 10. Get the 3 products with the highest stock value: show name and price * stock AS inventory_value, sorted by that value descending; break ties by name. Hint: ORDER BY price * stock DESC, name LIMIT 3.
Exercise 11. 🔥 Stretch. For the 'Điện tử' category only: show name, price, and the price at a 15% discount ROUND(price * 0.85) AS sale_price, sorted by price descending.

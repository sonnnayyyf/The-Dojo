1. The customer overview

Start with a summary table: each customer, their order count, and total spend — leaving no one out (including non-buyers).

SELECT c.name AS customer,
       COUNT(DISTINCT o.id) AS orders,
       COALESCE(SUM(p.price * oi.qty), 0) AS spent
FROM customers c
LEFT JOIN orders o       ON o.customer_id = c.id
LEFT JOIN order_items oi ON oi.order_id = o.id
LEFT JOIN products p     ON oi.product_id = p.id
GROUP BY c.id
ORDER BY spent DESC, c.id;
Exercise 1. Build the table above: c.name AS customer, COUNT(DISTINCT o.id) AS orders, COALESCE(SUM(p.price * oi.qty), 0) AS spent; LEFT JOIN all four tables; group by c.id; sort by spent descending then c.id.
Exercise 2. Top-spending customer (buyers only): c.name AS customer, SUM(p.price * oi.qty) AS spent, join orders → order_items → products → customers, group by c.id, sort by spent descending, take 1.

2. Filtering by behaviour

Exercise 3. Customers who spent over 100000: c.name AS customer, SUM(p.price * oi.qty) AS spent (join four tables), group by c.id, use HAVING SUM(p.price * oi.qty) > 100000, sort by spent descending.
Exercise 4. Number of distinct products each customer bought: c.name AS customer, COUNT(DISTINCT oi.product_id) AS products (join orders → order_items → customers), group by c.id, sort by products descending then c.id.
Exercise 5. Repeat customers (more than 1 order): c.name AS customer, COUNT(*) AS orders (join orders to customers), group by c.id, use HAVING COUNT(*) > 1, sort by c.id.

3. Deeper analysis

Exercise 6. Customer 1's spend by category: p.category, SUM(p.price * oi.qty) AS spent, join orders → order_items → products, filter o.customer_id = 1, group by p.category, sort by spent descending.
Exercise 7. Each customer's first order date: c.name AS customer, MIN(o.order_date) AS first_order (join customers to orders), group by c.id, sort by first_order.
Exercise 8. Revenue by city (buyers only): c.city, SUM(p.price * oi.qty) AS spent (join four tables), group by c.city, sort by spent descending.

4. Segmentation and contribution

Exercise 9. Customer segments (leaving no one out): c.name AS customer, COALESCE(SUM(p.price * oi.qty), 0) AS spent, and a segment column = 'VIP' if spend ≥ 100000, 'regular' if spend > 0, otherwise 'inactive'. Use LEFT JOIN on four tables, group by c.id, sort by spent descending then c.id.
Exercise 10. Each customer's share of total revenue (buyers only): c.name AS customer, ROUND(SUM(p.price * oi.qty) * 100.0 / (SELECT SUM(pp.price * oii.qty) FROM order_items oii JOIN products pp ON oii.product_id = pp.id)) AS pct, join four tables, group by c.id, sort by pct descending.

5. The final report

Exercise 11. 🔥 Stretch. Full customer report (buyers only): c.name AS customer, COUNT(DISTINCT o.id) AS orders, SUM(p.price * oi.qty) AS spent, and ROUND(SUM(p.price * oi.qty) * 1.0 / COUNT(DISTINCT o.id)) AS avg_order (that customer's average order value). Join four tables, group by c.id, sort by spent descending.

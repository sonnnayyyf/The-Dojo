Lesson 7 — Text & number functions

SQL doesn't just fetch data — it can transform it right in the query. Want the first few characters of a name? To strip the "TP." prefix off a city? To round a price to one decimal? There's a built-in function for each.

This lesson gathers the most useful functions for text (LENGTH, SUBSTR, REPLACE, concatenation with ||) and for numbers (ROUND, integer division). Dates have their own set of functions — you'll learn those in Lesson 8.

As always, give every computed column a name with AS.

1. LENGTH — count characters

LENGTH(text) returns the number of characters in a string.

SELECT name, LENGTH(name) AS name_len
FROM products;
Exercise 1. Show name and its length LENGTH(name) AS name_len.
Exercise 2. From customers, show name and the length of the city name LENGTH(city) AS city_len.

2. SUBSTR — cut a slice

SUBSTR(text, start, length) cuts out a substring. The first position is 1.

SELECT name, SUBSTR(name, 1, 3) AS prefix
FROM products;
Exercise 3. Show name and the first 3 characters: SUBSTR(name, 1, 3) AS prefix.
Exercise 4. Show name and the first 6 characters: SUBSTR(name, 1, 6) AS first6.

3. REPLACE — swap text

REPLACE(text, find, replace) swaps every occurrence of a substring.

SELECT name, REPLACE(city, 'TP. ', '') AS short_city
FROM customers;
Exercise 5. From customers, strip the 'TP. ' prefix off city: REPLACE(city, 'TP. ', '') AS short_city. Show name and short_city.

4. Joining text with ||

The || operator concatenates strings (you met it in Lesson 3). Combine columns with static characters to build a readable label.

SELECT name || ' - ' || category AS label
FROM products;
Exercise 6. Build a label column in the form name - category with name || ' - ' || category.

5. Number function: ROUND

ROUND(number) rounds to a whole number; ROUND(number, k) rounds to k decimal places.

SELECT name, ROUND(price * 1.1 / 1000.0, 1) AS k_vat
FROM products;
Exercise 7. Show name and the price (with 10% VAT) in thousands, to one decimal: ROUND(price * 1.1 / 1000.0, 1) AS k_vat.
Exercise 8. Show name and the price after a 10% discount, rounded to a whole number: ROUND(price * 0.9) AS sale_price.

6. Integer division

Dividing two integers in SQL gives the whole-number part (the remainder is dropped). It's a quick way to express a price in "thousands".

Exercise 9. Show name and the price in thousands using integer division: price / 1000 AS price_k.

7. Using functions in WHERE

Functions also work in WHERE for filtering. For example, find products with long names.

Exercise 10. Find products with a name longer than 15 characters: show name and LENGTH(name) AS name_len, filter LENGTH(name) > 15, sorted by name_len descending then name.

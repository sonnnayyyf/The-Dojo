Lesson 7 — CASE WHEN & functions (text, number, date)

Raw data isn't always in the shape you need. A manager doesn't want to see 350000 — they want the label "premium". The joined_at column is '2024-01-10' but a report only needs the year. This is where CASE WHEN and SQL's built-in functions turn raw data into readable information.

CASE WHEN is SQL's "if/else": it looks at each row and returns a value depending on a condition. SQL also ships with functions for text (LENGTH, SUBSTR, REPLACE), numbers (ROUND), and dates (strftime).

Every column you create here should get an AS alias for a clear name — as you learned in Lesson 4.

1. CASE WHEN — labels by condition

Syntax: CASE WHEN condition THEN value ... ELSE default END. SQL checks the branches top to bottom and stops at the first true one.

SELECT name,
  CASE WHEN price >= 100000 THEN 'high'
       WHEN price >= 20000  THEN 'medium'
       ELSE 'low' END AS tier
FROM products;
Exercise 1. For each product, build a tier column: 'high' if price >= 100000, 'medium' if price >= 20000, otherwise 'low'. Show name and tier.

3. CASE returning a number

CASE doesn't only return text — it can return numbers too, perfect for a conditional calculation.

SELECT name,
  ROUND(CASE WHEN category = 'Điện tử' THEN price * 0.85
             ELSE price * 0.95 END) AS final_price
FROM products;
Exercise 3. Compute final_price: 'Điện tử' items get 15% off (price * 0.85), everything else 5% off (price * 0.95), then ROUND. Show name and final_price.

4. Text functions: LENGTH, SUBSTR

LENGTH(text) counts characters. SUBSTR(text, start, length) cuts out a slice (the first position is 1).

SELECT name, LENGTH(name) AS name_len
FROM products;
Exercise 4. Show name and its length LENGTH(name) AS name_len.

5. Text functions: REPLACE

REPLACE(text, find, replace) swaps every occurrence of a substring.

SELECT name, REPLACE(city, 'TP. ', '') AS short_city
FROM customers;
Exercise 6. From customers, strip the 'TP. ' prefix from city: REPLACE(city, 'TP. ', '') AS short_city. Show name and short_city.

6. Date functions

Dates are stored as 'YYYY-MM-DD'. You can slice them with SUBSTR, or use strftime to extract a part: strftime('%Y', date) for the year, '%m' for the month.

SELECT name, SUBSTR(joined_at, 1, 4) AS year
FROM customers;
Exercise 7. From customers, get the join year by slicing the first 4 characters: SUBSTR(joined_at, 1, 4) AS year. Show name and year.

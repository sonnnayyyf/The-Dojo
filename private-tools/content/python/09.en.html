Lesson 9 — Setup: Python + VS Code

Until now you have run Python right here in the browser. That playground is perfect for learning because the feedback is instant — but it is not where real programs live. Professional developers write their code in files on their own computer, using a proper code editor, and run those files with the real Python that they installed. This lesson is the bridge from the playground to that real workflow.

There are two halves. The first is a short, one-time setup: install Python and install VS Code (the free editor most Python developers use). The second, and bigger, half is a set of warm-up exercises that prepare you for the next lesson's mini-project — a small to-do / task manager. You will still run those exercises here in the browser so you keep the instant checking while you practise the pieces you'll soon assemble.

From here on your homework moves into real VS Code instead of being auto-graded on the site — so getting the tools working is the important first step. Take your time with the setup; everything after it is familiar list, loop and string work aimed at one goal: a working task list.

1. Get your tools (one-time setup)

You only do this once. Three small steps:

2. How code runs from a file

In the browser, your code ran the moment you pressed ▶. On your computer the loop is slightly longer but just as simple: you write code into a .py file, VS Code hands that file to Python, and Python runs it top to bottom and shows the output in the terminal.

The good news: the Python language is exactly the same as in this playground. Everything you already know — lists, loops, if, f-strings — works identically in a file. So let's warm up on the building blocks of a task manager.

3. A task list is just a list of strings

A to-do app is, at heart, a list of strings where each string is one task. You already know how to grow a list with append.

tasks = []
tasks.append("Buy milk")
tasks.append("Call Anna")
print(tasks)   # ['Buy milk', 'Call Anna']
Exercise 1. Start with tasks = [] and append three tasks in order: "Buy milk", "Call Anna", "Wash car". Result ['Buy milk', 'Call Anna', 'Wash car'].
Exercise 2. Given tasks = ["Buy milk", "Call Anna"], add "Pay bills" to the end. Result ['Buy milk', 'Call Anna', 'Pay bills'].

4. Removing and finding a task

Users also finish or cancel tasks. list.remove(value) deletes the first matching item; to know where a task is, walk the list and compare.

tasks = ["Buy milk", "Call Anna", "Wash car"]
tasks.remove("Call Anna")
print(tasks)                 # ['Buy milk', 'Wash car']
print("Wash car" in tasks)   # True — membership check
Exercise 3. Given tasks = ["Buy milk", "Call Anna", "Wash car"], remove "Call Anna". Result ['Buy milk', 'Wash car'].
Exercise 4. Given tasks = ["Buy milk", "Call Anna", "Wash car"], set has_call to whether "Call Anna" is in the list. Result True.
Exercise 5. Given tasks = ["Buy milk", "Call Anna", "Wash car"], find the index of "Wash car" by looping, and store it in pos (start pos = -1). Result 2.

5. Showing a numbered menu

People count from 1, but list indexes start at 0 — so a menu line for the task at index i shows the number i + 1. Build each line with an f-string.

tasks = ["Buy milk", "Call Anna"]
for i in range(len(tasks)):
    print(f"{i + 1}. {tasks[i]}")
# 1. Buy milk
# 2. Call Anna

6. Marking a task done

A common trick: mark a finished task by putting a tag in front of its text, like "[x] ". Then a task is "done" when it starts with that tag (task.startswith("[x] ")).

tasks = ["Buy milk", "Call Anna"]
done = []
for t in tasks:
    done.append("[x] " + t)
print(done)   # ['[x] Buy milk', '[x] Call Anna']
Exercise 8. Given tasks = ["Buy milk", "Call Anna", "Wash car"], build done where every task is prefixed with "[x] " → ['[x] Buy milk', '[x] Call Anna', '[x] Wash car'].
Exercise 9. Given tasks = ["[x] Buy milk", "Call Anna", "[x] Wash car"], count how many are done (start with "[x] ") into done_count. Result 2.

7. A little summary

The last piece before the mini-project: a summary line. Count the total and the done tasks, then format one clear sentence.

tasks = ["[x] Buy milk", "Call Anna", "[x] Wash car"]
total = len(tasks)
done = 0
for t in tasks:
    if t.startswith("[x] "):
        done += 1
print(f"{done} of {total} tasks done")   # 2 of 3 tasks done
Exercise 10. Given tasks = ["[x] Buy milk", "Call Anna", "[x] Wash car", "Pay bills"], build the string summary = "2 of 4 tasks done" using len, a loop and an f-string.

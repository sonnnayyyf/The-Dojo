1. The shape of a real program

Most useful programs follow the same flow: messy input comes in, you turn it into tidy records, you compute something, and you present a result. Each stage is just the skills you already have.

def parse_score(line):
    name, score = line.split(",")
    return (name, int(score))

print(parse_score("Anna,85"))   # ('Anna', 85)
Exercise 1. Define parse_score that takes a line like "Anna,85" and returns a tuple (name, score) with the score as an int. So parse_score("Anna,85") is ("Anna", 85).
Exercise 2. Define safe_parse that works like parse_score but returns None if the line is malformed (no comma, or a non-number score). So safe_parse("Anna,85") is ("Anna", 85) and safe_parse("oops") is None.

2. Analysing records

Once data is a list of (name, score) tuples, all your loop, sum and filter skills apply directly.

records = [("A", 50), ("B", 80), ("C", 65)]
total = 0
for name, score in records:
    total += score
print(total)   # 195
Exercise 3. Define total_score that sums the scores in a list of (name, score) tuples. So total_score([("A", 10), ("B", 20), ("C", 5)]) is 35.
Exercise 4. Define average_score that returns the average score of a non-empty record list. So average_score([("A", 2), ("B", 4)]) is 3.0.
Exercise 5. Define passing that returns the names whose score is at least cutoff. So passing([("A", 50), ("B", 80), ("C", 65)], 60) is ["B", "C"].
Exercise 6. Define ranked_scores that returns just the scores, sorted from highest to lowest. So ranked_scores([("A", 50), ("B", 80), ("C", 65)]) is [80, 65, 50].

3. Counting and finding the top

The counting pattern plus a "biggest so far" search — the heart of any "what's most common" report.

def count_words(text):
    counts = {}
    for w in text.split():
        counts[w] = counts.get(w, 0) + 1
    return counts

print(count_words("a b a c a"))   # {'a': 3, 'b': 1, 'c': 1}
Exercise 7. Define count_words that returns a word → count dictionary for a sentence. So count_words("a b a c a") is {'a': 3, 'b': 1, 'c': 1}.
Exercise 8. Define top_word that takes a word → count dictionary and returns the word with the highest count. So top_word({"a": 3, "b": 1}) is "a".

4. Building a report

The finish line of a program: gather your numbers into one clear summary — usually a dictionary of results.

records = [("A", 50), ("B", 80), ("C", 65)]
report = {
    "count": len(records),
    "total": sum(score for name, score in records),
}
print(report)   # {'count': 3, 'total': 195}
Exercise 9. Define analyse that takes a non-empty record list and returns a dictionary with count, total, average, and top (the name with the highest score). So analyse([("A", 50), ("B", 80), ("C", 65)]) is {"count": 3, "total": 195, "average": 65.0, "top": "B"}.
🔥 Stretch (text analyser). Define analyse_text that takes a sentence and returns {"words": total_word_count, "unique": distinct_word_count, "top": most_common_word}. So analyse_text("red blue red green red") is {"words": 5, "unique": 3, "top": "red"}. This is a mini version of the capstone!

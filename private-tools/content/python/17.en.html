Lesson 17 — Sets & sorting basics

Two everyday needs come up constantly once you handle real data: getting rid of duplicates, and putting things in order. Python has a clean tool for each. A set is a collection that automatically keeps only unique values — perfect for "how many different things are here?". And sorted() takes any list and hands back a tidy, ordered copy.

Along the way you'll meet three tiny built-in functions you'll use forever: min, max, and sum. Together with sets and sorting, they turn a pile of numbers into answers — the smallest, the largest, the total, the ranking — in a single line.

This keeps things firmly at the fundamentals level: we sort with plain sorted() and reverse=True. (Custom sort orders with key come in the Intermediate course.)

1. Sets: unique values

A set uses curly braces like a dict, but holds single values, not pairs. Its superpower: it silently drops duplicates. Turning a list into a set is the standard way to find the distinct items.

nums = [1, 2, 2, 3, 3, 3]
unique = set(nums)
print(unique)        # {1, 2, 3}
print(len(unique))   # 3  — three distinct values
Exercise 1. Given nums = [1, 2, 2, 3, 3, 3], set distinct to how many different values there are. Result 3. (Use set and len.)
Exercise 2. Given tags = {"python", "sql", "qa"}, set has_sql to whether "sql" is in the set. Result True. (Membership on a set is very fast.)

2. Combining sets

Sets can be combined like in maths: | is union (everything in either), & is intersection (only what's in both).

a = {1, 2, 3}
b = {2, 3, 4}
print(a | b)   # {1, 2, 3, 4}  — union
print(a & b)   # {2, 3}        — in both
Exercise 3. Given a = {1, 2, 3} and b = {2, 3, 4}, build combined = their union → {1, 2, 3, 4}.
Exercise 4. Given the same a and b, build shared = the values in both → {2, 3}.

3. Sorting with sorted()

sorted(list) returns a new list in ascending order — it doesn't change the original. Add reverse=True for descending. It works on numbers and, alphabetically, on strings.

nums = [3, 1, 2]
print(sorted(nums))               # [1, 2, 3]
print(sorted(nums, reverse=True)) # [3, 2, 1]
print(sorted(["banana", "apple", "cherry"]))  # ['apple', 'banana', 'cherry']
Exercise 5. Given nums = [3, 1, 2], build ordered = the numbers sorted ascending → [1, 2, 3].
Exercise 6. Given nums = [3, 1, 2], build desc = the numbers sorted from biggest to smallest → [3, 2, 1]. (Use reverse=True.)
Exercise 7. Given words = ["banana", "apple", "cherry"], build alpha = the words in alphabetical order → ['apple', 'banana', 'cherry'].

4. min, max, sum

Three built-ins that answer the most common questions about a list of numbers in one word each.

nums = [4, 2, 8, 6]
print(min(nums))   # 2
print(max(nums))   # 8
print(sum(nums))   # 20
Exercise 8. Given nums = [4, 2, 8, 6], set lowest, highest, and total using min, max, and sum. Results 2, 8, 20.
Exercise 9. Given nums = [3, 1, 2, 3, 1], build unique_sorted = the distinct values in ascending order → [1, 2, 3]. (Combine set and sorted.)
🔥 Stretch (top three). Given nums = [5, 2, 8, 1, 9, 3], build top3 = the three largest values, biggest first → [9, 8, 5]. (Sort descending, then take the first three with [:3].)
Recap of lesson 17: a set holds only unique values — set(list) removes duplicates, membership (in) is fast, and | / & give union / intersection · sorted(list) returns a new ascending list, reverse=True for descending, and it works on strings alphabetically · min, max, sum answer smallest / largest / total in one word · combine them (e.g. sorted(set(...))) for distinct, ordered results.

Lesson 2 — Strings and f-strings

Strings are the data type you meet most in programming: usernames, file names, paths, error messages, content read from the web… all strings. Mastering strings is mastering half of everyday programming. This lesson covers how to measure, access, slice, transform, join and format them.

1. A string is a sequence of characters

name = "python"
print(len(name))   # 6 — len() gives the length (number of characters)

Strings can use single or double quotes, as long as they match:

a = "hello"
b = 'hello'   # equivalent

2. Indexing — accessing individual characters

Each character has an index, counting from 0. Negative indexes count back from the end:

s = "python"
#     p  y  t  h  o  n
#     0  1  2  3  4  5
#    -6 -5 -4 -3 -2 -1
print(s[0])    # 'p' — first char
print(s[-1])   # 'n' — last char
Exercise 2. Given s = "python", take the first character into first and the last into last (use indexing).

3. Slicing

The syntax s[start:stop] takes from index start up to just before stop:

s = "python"
print(s[0:3])   # 'pyt' — index 0,1,2
print(s[2:])    # 'thon' — from index 2 to the end
print(s[:3])    # 'pyt' — from start to before 3
print(s[-3:])   # 'hon' — last 3 chars
Exercise 3. Given filename = "bao_cao.txt", take the last 3 characters (the extension) into ext.

4. Joining and repeating

first = "Nguyen"
last = "Minh"
print(first + " " + last)   # 'Nguyen Minh' — join with +
print("=" * 10)              # '==========' — repeat 10x with *
Exercise 4. Given first_name = "Le" and last_name = "An", join into full_name = "Le An" (one space between).

5. Escape sequences

A few characters need "escaping" with a backslash \:

print("Line 1\nLine 2")      # \n = new line
print("Col1\tCol2")           # \t = tab
print("He said \"hi\"")       # \" = a quote inside a double-quoted string
print("C:\\tmp\\a.txt")        # \\ = a single backslash
Exercise 5. Create cau holding exactly: Anh ay noi "hello" (with double quotes around hello).

6. Strings are immutable

You cannot change a character by assigning to an index. Every string method returns a new string and leaves the original untouched:

s = "python"
# s[0] = "P"        # ERROR: 'str' object does not support item assignment
s = "P" + s[1:]      # the right way: build a new string
print(s)              # Python

7. String methods

Strings come with built-in "tools" called with a dot:

"  hi  ".strip()            # 'hi'   — trim both ends
"hello".upper()             # 'HELLO'
"HELLO".lower()             # 'hello'
"hello world".title()       # 'Hello World'
"a-b-c".replace("-", "_")   # 'a_b_c'
"python".startswith("py")   # True
"a.txt".endswith(".txt")    # True
"banana".count("a")         # 3
"banana".find("na")         # 2   (first position, or -1 if not found)

Check whether one string is inside another with the in keyword:

print("py" in "python")     # True
print("z" in "python")      # False

8. f-strings — insert and format

The modern, most readable way to put values into a string: add f before the quote and put variables (or expressions) in { }.

name = "Minh"
age = 15
print(f"Name is {name}, age {age}")   # Name is Minh, age 15
print(f"Next year: {age + 1}")         # compute right inside { }

f-strings also format the value after a colon :

price = 2500000
print(f"{price:,} VND")     # 2,500,000 VND  — thousands separator
score = 8.6666
print(f"{score:.2f}")       # 8.67           — round to 2 decimals
name = "Minh"
print(f"|{name:>10}|")     # |      Minh|   — right-align, width 10
print(f"|{name:<10}|")     # |Minh      |   — left-align
print(f"|{name:^10}|")     # |   Minh   |   — center

9. Splitting & joining (preview)

Two very useful methods (covered in depth in lesson 19):

  • "a,b,c".split(",") → ['a', 'b', 'c'] — split a string into a list.
  • "-".join(["a", "b", "c"]) → "a-b-c" — join a list into a string.
full_name = "Nguyen Van Minh"
parts = full_name.split(" ")     # ['Nguyen', 'Van', 'Minh']
print(parts)
print(len(parts), "words")       # 3 words

You can also chain methods — they run left to right:

raw = "  Hello WORLD  "
print(raw.strip().lower())       # 'hello world'

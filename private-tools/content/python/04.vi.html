Bài 4 — Logic boolean & điều kiện lồng nhau

Bài trước bạn ra quyết định với một điều kiện. Đời thật phức tạp hơn: "đủ 18 tuổi và có bằng lái", "cuối tuần hoặc ngày lễ". Bài này học cách kết hợp nhiều điều kiện và lồng điều kiện vào nhau.

1. Ba toán tử logic: and, or, not

  • and — đúng khi cả hai vế đều đúng.
  • or — đúng khi ít nhất một vế đúng.
  • not — đảo ngược: not True → False.
print(True and False)   # False — can CA HAI dung
print(True or False)    # True  — chi can MOT dung
print(not True)         # False — dao nguoc

2. Bảng chân trị (nhìn là nhớ)

ABA and BA or B
TrueTrueTrueTrue
TrueFalseFalseTrue
FalseTrueFalseTrue
FalseFalseFalseFalse

Mẹo nhớ: and khó tính (chỉ đúng khi mọi thứ đúng), or dễ tính (chỉ cần một cái đúng).

age = 25
has_ticket = True
if age >= 18 and has_ticket:
    print("Duoc vao rap")
Bài tập 1. Cho age = 25 và has_ticket = True. Tạo can_enter = True nếu vừa đủ 18 tuổi trở lên vừa có vé (dùng and).
Bài tập 2. Cho is_weekend = False và is_holiday = True. Tạo day_off = True nếu cuối tuần hoặc ngày lễ (dùng or).
Bài tập 3. Cho is_busy = False. Tạo is_free = đảo ngược của is_busy (dùng not).

3. So sánh nối chuỗi: 0 <= x <= 100

Python cho phép viết khoảng gọn như toán học. Rất tiện để kiểm tra một giá trị có nằm trong khoảng hợp lệ không.

score = 75
print(0 <= score <= 100)   # True — score nam trong [0, 100]
# tuong duong: score >= 0 and score <= 100
Bài tập 4. Cho score = 75. Tạo is_valid = True nếu score nằm trong khoảng từ 0 đến 100 (dùng so sánh nối chuỗi hoặc and).

4. Kết hợp trong bài toán thật

n = 15
if n % 3 == 0 and n % 5 == 0:
    print("FizzBuzz")     # chia het CA 3 va 5
Bài tập 5. Cho age = 20 và has_license = True. Tạo can_drive = True nếu đủ 18 tuổi và có bằng lái.
Bài tập 6. Cho user = "admin" và pw = "1234". Tạo message = "OK" nếu user đúng là "admin" và pw đúng là "1234", ngược lại "Wrong".

5. Điều kiện lồng nhau (nested if)

Bạn có thể đặt một if bên trong một if khác — mỗi mức lồng thụt vào thêm 4 dấu cách. Dùng khi câu hỏi thứ hai chỉ có ý nghĩa sau khi câu hỏi đầu đã đúng.

score = 8
attendance = True
if score >= 8:
    if attendance:
        scholarship = "Full scholarship"
    else:
        scholarship = "Review attendance"
else:
    scholarship = "Score too low"
print(scholarship)    # Duoc hoc bong

Khi nào lồng, khi nào dùng and? Nếu chỉ cần "cả hai đúng" thì and gọn hơn. Lồng dùng khi mỗi tầng có xử lý riêng (như ví dụ trên: điểm đủ nhưng thiếu chuyên cần vẫn có nhánh riêng).

Bài tập 7. Cho score = 8 và attendance = True. Dùng if lồng nhau tạo scholarship: nếu score >= 8 thì — nếu attendance đúng → "yes", ngược lại → "review"; nếu điểm chưa đủ → "no".

6. Biến boolean làm "cờ" (flag)

Lưu kết quả một điều kiện vào biến bool giúp code dễ đọc hơn nhiều:

age = 20
income = 8
loan_ok = age >= 18 and income >= 5
if loan_ok:
    print("Duoc vay")
Bài tập 8. Cho hours = 10 và is_member = True. Tạo cờ gets_discount = True nếu (giờ mở cửa: 8 <= hours <= 22) và là thành viên.

7. Giá trị "giả" (falsy) & viết gọn

Trong điều kiện, một số giá trị được coi là sai (falsy) dù không phải False: số 0, chuỗi rỗng "", danh sách rỗng [], và None. Mọi thứ khác là đúng (truthy).

name = ""
if name:
    print("Co ten")
else:
    print("Chua nhap ten")   # chay, vi "" la falsy

Nhờ vậy có thể viết gọn if name: thay cho if name != "":.

Bài tập 9. Cho cart = [] (danh sách rỗng). Tạo is_empty = True nếu giỏ hàng rỗng (gợi ý: not cart — danh sách rỗng là falsy).

8. Những lỗi thường gặp

  • Dùng &&, ||, ! như các ngôn ngữ khác — Python dùng chữ and, or, not.
  • Quên rằng and "khó tính" hơn or: khi trộn cả hai, dùng ngoặc cho rõ: (a and b) or c.
  • Lồng quá sâu (3–4 tầng if) → khó đọc; thường có thể gộp bằng and hoặc tách hàm (học ở bài về hàm).
Ghi nhớ bài 4: and (cả hai đúng) · or (ít nhất một đúng) · not (đảo) · so sánh nối chuỗi 0 <= x <= 100 · if lồng nhau khi mỗi tầng cần xử lý riêng · giá trị falsy (0, "", [], None) · lưu điều kiện vào biến bool (cờ). Bài sau: danh sách (list) và chỉ số — cách lưu nhiều giá trị.
🔥 Thử thách. Cho age = 70. Tạo price (giá vé): dưới 6 tuổi → 0; dưới 18 hoặc từ 60 trở lên → 50; còn lại → 100. Xét trẻ nhỏ trước, rồi nhóm ưu đãi.

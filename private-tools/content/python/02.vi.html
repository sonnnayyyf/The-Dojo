Bài 2 — Chuỗi (string) và f-string

Chuỗi là kiểu dữ liệu bạn gặp nhiều nhất khi lập trình: tên người dùng, tên file, đường dẫn, thông báo lỗi, nội dung đọc từ web… tất cả đều là chuỗi. Làm chủ chuỗi là làm chủ một nửa công việc lập trình đời thường. Bài này học cách đo, truy cập, cắt, biến đổi, ghép và định dạng chuỗi.

1. Chuỗi là một dãy ký tự

last_name = "python"
print(len(last_name))   # 6 — len() cho biet do dai (so ky tu)

Chuỗi có thể dùng nháy đơn hay nháy kép, miễn là mở và đóng giống nhau:

a = "xin chao"
b = 'xin chao'   # tuong duong
Bài tập 1. Tạo biến filename = "bao_cao.txt" và biến length bằng độ dài của nó (dùng len).

2. Chỉ số (index) — truy cập từng ký tự

Mỗi ký tự có một chỉ số, đếm từ 0. Chỉ số âm đếm ngược từ cuối:

s = "python"
#     p  y  t  h  o  n
#     0  1  2  3  4  5
#    -6 -5 -4 -3 -2 -1
print(s[0])    # 'p' — ky tu first
print(s[-1])   # 'n' — ky tu last
Bài tập 2. Cho s = "python". Lấy ký tự đầu vào first và ký tự cuối vào last (dùng chỉ số).

3. Cắt chuỗi (slicing)

Cú pháp s[start:stop] lấy từ chỉ số start đến ngay trước stop:

s = "python"
print(s[0:3])   # 'pyt' — index 0,1,2
print(s[2:])    # 'thon' — tu index 2 den het
print(s[:3])    # 'pyt' — tu first den truoc 3
print(s[-3:])   # 'hon' — 3 ky tu last
Bài tập 3. Cho filename = "bao_cao.txt". Lấy 3 ký tự cuối (phần mở rộng) vào ext.

4. Ghép và lặp chuỗi

first_name = "Nguyen"
last_name = "Minh"
print(first_name + " " + last_name)   # 'Nguyen Minh' — ghep bang +
print("=" * 10)          # '==========' — lap 10 lan bang *
Bài tập 4. Cho first_name = "Le" và last_name = "An". Ghép thành full_name = "Le An" (một dấu cách ở giữa).

5. Ký tự đặc biệt (escape)

Vài ký tự cần "thoát" bằng dấu gạch chéo ngược \:

print("Dong 1\nDong 2")      # \n = xuong dong
print("Cot1\tCot2")           # \t = tab
print("Anh ay noi \"hi\"")   # \" = first nhay ben trong chuoi kep
print("C:\\tmp\\a.txt")        # \\ = mot first gach cheo nguoc
Bài tập 5. Tạo biến cau chứa đúng nội dung: Anh ay noi "hello" (có cặp dấu nháy kép quanh chữ hello).

6. Chuỗi không sửa được tại chỗ (immutable)

Bạn không thể đổi một ký tự bằng cách gán vào chỉ số. Mọi phương thức chuỗi luôn trả về một chuỗi mới, không đụng vào chuỗi gốc:

s = "python"
# s[0] = "P"        # LOI: 'str' object does not support item assignment
s = "P" + s[1:]      # dung cach: tao chuoi moi
print(s)              # Python

7. Phương thức chuỗi (string methods)

Chuỗi có sẵn nhiều "công cụ" gọi bằng dấu chấm:

"  hi  ".strip()            # 'hi'   — bo khoang trang 2 first
"hello".upper()             # 'HELLO'
"HELLO".lower()             # 'hello'
"hello world".title()       # 'Hello World'
"a-b-c".replace("-", "_")   # 'a_b_c'
"python".startswith("py")   # True
"a.txt".endswith(".txt")    # True
"banana".count("a")         # 3
"banana".find("na")         # 2   (vi tri first tien, hoac -1 neu khong thay)

Kiểm tra một chuỗi có nằm trong chuỗi khác bằng từ khóa in:

print("py" in "python")     # True
print("z" in "python")      # False
Bài tập 6. Cho email = " Minh@Example.COM ". Chuẩn hóa: bỏ khoảng trắng thừa và đổi về chữ thường, lưu vào cleaned.
Bài tập 7. Cho path = "src/app/main". Thay mọi dấu / bằng dấu . để được src.app.main, lưu vào module.
Bài tập 8. Cho filename = "bao_cao.txt". Tạo biến is_txt = kết quả kiểm tra tên file có kết thúc bằng ".txt" hay không (dùng .endswith, kết quả là True/False).

8. f-string — chèn và định dạng

Cách hiện đại và dễ đọc nhất để chèn giá trị vào chuỗi: thêm chữ f trước dấu nháy, đặt biến (hoặc biểu thức) trong { }.

last_name = "Minh"
tuoi = 15
print(f"Ten la {last_name}, {tuoi} tuoi")   # Ten la Minh, 15 tuoi
print(f"Sang nam {tuoi + 1} tuoi")     # tinh toan ngay trong { }

f-string còn định dạng giá trị sau dấu hai chấm :

price = 2500000
print(f"{price:,} VND")     # 2,500,000 VND  — first phay ngan cach hang nghin
score = 8.6666
print(f"{score:.2f}")       # 8.67           — lam tron 2 chu so thap phan
last_name = "Minh"
print(f"|{last_name:>10}|")      # |      Minh|   — can le phai, rong 10
print(f"|{last_name:<10}|")      # |Minh      |   — can le trai
print(f"|{last_name:^10}|")      # |   Minh   |   — can giua
Bài tập 9. Cho price = 2500000. Dùng f-string tạo display = "2,500,000 VND" (có dấu phẩy ngăn cách hàng nghìn).
Bài tập 10. Cho score = 8.6666. Dùng f-string tạo rounded = "8.67" (làm tròn 2 chữ số thập phân).

9. Nối & tách chuỗi (xem trước)

Hai phương thức cực hữu ích (sẽ học kỹ ở bài 19):

  • "a,b,c".split(",") → ['a', 'b', 'c'] — tách chuỗi thành danh sách.
  • "-".join(["a", "b", "c"]) → "a-b-c" — nối danh sách thành chuỗi.
full_name = "Nguyen Van Minh"
parts = full_name.split(" ")     # ['Nguyen', 'Van', 'Minh']
print(parts)
print(len(parts), "tu")          # 3 tu

Bạn cũng có thể nối chuỗi các method lại — chúng chạy lần lượt từ trái sang phải:

raw = "  Hello WORLD  "
print(raw.strip().lower())       # 'hello world'
Bài tập 11. Cho sentence = "python la ngon ngu". Tách thành danh sách các từ (theo dấu cách) rồi lưu số từ vào word_count (dùng split rồi len).
Ghi nhớ bài 2: chuỗi là dãy ký tự, index từ 0 (âm đếm từ cuối) · len() đo độ dài · [a:b] cắt · + ghép, * lặp · \n \t \" \\ ký tự đặc biệt · chuỗi immutable — method trả về chuỗi mới · .strip/.lower/.upper/.title/.replace/.startswith/.endswith/.count/.find/.split · in để kiểm tra chứa · f-string f"{bien:dinh_dang}" để chèn và định dạng. Bài sau: ra quyết định với if/elif/else.
🔥 Thử thách. Cho full = " John.DOE@Company.com ". Tạo username = phần trước dấu @ đã chuẩn hóa (strip + lower), và domain = phần sau @ đã chuẩn hóa. Kết quả: username = "john.doe", domain = "company.com". (Gợi ý: .strip().lower() trước, rồi .find("@") và cắt chuỗi.)

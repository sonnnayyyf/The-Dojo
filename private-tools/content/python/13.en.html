Lesson 13 — Functions: naming a block of code

Look back at your lessons so far and you'll notice the same little routines popping up again and again: check if a task is done, format a line, count something. Copying that logic everywhere is slow and dangerous — fix a bug in one copy and the other five are still wrong. There has to be a way to write a piece of logic once, give it a name, and reuse it. There is: the function.

A function is a named, reusable machine. You define it once, then call it by name whenever you need it — optionally feeding it inputs (arguments) and getting an output back (a return value). You've already been calling functions the whole course: print(...), len(...), round(...) are all functions someone else wrote. Now you'll write your own.

This is a turning point. Functions are how real programs stay organised: instead of one giant wall of code, you build small, named pieces that each do one job — easy to read, test, and reuse. Master this and everything after it gets easier.

1. Defining and calling a function

You define a function with def, a name, parentheses, and a colon. The indented lines below are its body — they don't run until you call the function by writing its name with ().

def say_hello():
    print("Hello!")
    print("Welcome to The Dojo.")

say_hello()      # call it — now the body runs
say_hello()      # call it again — reuse!

Defining a function does not run it — it just teaches Python what the function does. Nothing happens until you call it. Calling it twice runs the body twice.

2. Parameters: giving a function input

A function becomes far more useful when it can work on different values. Put a parameter name in the parentheses; when you call the function you pass an argument that fills it in.

def greet(name):
    print(f"Hello, {name}!")

greet("Anna")    # Hello, Anna!
greet("Ben")     # Hello, Ben!

3. return vs print — the big one

This trips up every beginner, so read slowly. print shows a value on the screen and then it's gone. return hands a value back to whoever called the function, so it can be stored and used. A function that only prints gives you nothing to work with.

def add_print(a, b):
    print(a + b)          # shows it, returns nothing

def add_return(a, b):
    return a + b          # hands the value back

x = add_return(2, 3)
print(x * 10)             # 50 — we could use the returned value

y = add_print(2, 3)       # prints 5...
print(y)                  # None — there was nothing to store!

Rule of thumb: if you want to use a function's result later, it must return it.

4. Several parameters

A function can take as many inputs as you need, separated by commas. The arguments fill the parameters in order.

def add(a, b):
    return a + b

def total_price(price, qty):
    return price * qty

print(add(2, 3))            # 5
print(total_price(50, 3))   # 150

5. Returning a decision (True/False)

A function can return anything — including the result of a comparison, which is a boolean. That's a clean way to name a yes/no test.

def is_even(n):
    return n % 2 == 0

print(is_even(4))    # True
print(is_even(7))    # False

6. Using functions together

The real power: once a function exists, you can call it inside loops, inside other functions, anywhere. Small pieces combine into big programs.

def greet_name(name):
    return f"Hello, {name}!"

names = ["Anna", "Ben"]
for n in names:
    print(greet_name(n))
# Hello, Anna!
# Hello, Ben!
Exercise 9. Define greet_name that takes name and returns "Hello, name!". So greet_name("Anna") is "Hello, Anna!". (Use an f-string.)

Recap of lesson 13: a function is a named, reusable block · define with def name(params):, run it by calling name(args) · parameters are inputs, arguments fill them in · return hands a value back so it can be used — print only shows it and returns None · a function can return numbers, strings, or booleans · call functions inside loops and other functions to build bigger programs.

Lesson 8 — Nested loops

So far each loop walks a one-dimensional sequence. But many things in life are two-dimensional: a spreadsheet (rows × columns), a chessboard, a multiplication table, every pair of students in a class. To handle them, we put one loop inside another — called nested loops. This is the hardest part of the loops chapter, so we'll go carefully.

The core idea: for each pass of the outer loop, the inner loop runs completely from start to finish. If the outer runs 3 times and each time the inner runs 3 times, the innermost body runs 3 × 3 = 9 times total.

1. A loop inside a loop

for i in range(3):          # OUTER loop: i = 0, 1, 2
    for j in range(3):      # INNER loop: for each i, j runs 0,1,2
        print(i, j)
# prints 9 lines: 0 0 / 0 1 / 0 2 / 1 0 / 1 1 / 1 2 / 2 0 / 2 1 / 2 2

Notice the two indent levels: for j is inside the body of for i, and print is inside the body of for j (indented twice). The outer variable i "stays still" while the inner variable j runs a full cycle.

3. Building a "grid" (a list of lists)

A very common pattern: the outer loop creates each row (an empty list), the inner loop appends the cells into that row, and at the end of each row we append the whole row into the grid.

table = []
for i in range(1, 4):
    row = []                     # start a new row
    for j in range(1, 4):
        row.append(i * j)        # add a cell to the row
    table.append(row)            # add the whole row to the table
print(table)   # [[1, 2, 3], [2, 4, 6], [3, 6, 9]]

4. Walking an existing grid

Once you have a grid (a list of lists), you walk it with two loops too: the outer loop takes each row, the inner loop takes each cell in that row.

grid = [[1, 2], [3, 4]]
total = 0
for row in grid:           # row is [1,2] then [3,4]
    for cell in row:       # cell is each number
        total += cell
print(total)               # 1 + 2 + 3 + 4 = 10

5. Drawing shapes with loops

Repeating a string ("*" * i) together with a loop produces patterns — a classic exercise for building nested-loop intuition.

lines = []
for i in range(1, 4):
    lines.append("*" * i)
print(lines)   # ['*', '**', '***']

6. Comparing pairs

Nested loops also let you consider every pair of elements — e.g. finding two numbers that add up to a target.

nums = [1, 2, 3, 4]
target = 5
pairs = 0
for a in range(len(nums)):
    for b in range(a + 1, len(nums)):   # b > a to avoid repeating a pair
        if nums[a] + nums[b] == target:
            pairs += 1
print(pairs)   # (1,4) and (2,3) -> 2

Recap of lesson 8: nested loops = a loop inside a loop · for each outer pass, the inner runs completely → total runs = outer × inner · two indent levels · the grid-building pattern: new row → add cells → add row · walking a grid: for row in grid: for cell in row · consider every pair with two indexes (b starts at a+1).

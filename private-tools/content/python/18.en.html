Lesson 18 — Text toolkit: split, join & clean

So much of real programming is wrangling text: a line typed by a user, a row copied from a spreadsheet, a message, a search box. The data almost never arrives perfectly clean — it has stray spaces, mixed capitalisation, commas separating fields. This lesson is your toolkit for turning messy text into tidy data you can actually work with.

Three moves do most of the work: split a string into a list of pieces, join a list back into a string, and clean individual pieces with strip, lower, and replace. Add a couple of ways to search inside text and you can answer real questions — how many words, does it contain this, which word appears most.

These are also the exact skills behind your capstone next, where you'll analyse a block of text. Let's sharpen them.

1. Splitting text into pieces

split() with no argument breaks a string on spaces into a list of words. Give it a separator to split on something else — a comma, a slash, a dash.

print("the quick brown fox".split())   # ['the', 'quick', 'brown', 'fox']
print("a,b,c".split(","))              # ['a', 'b', 'c']
print("2024-01-15".split("-"))         # ['2024', '01', '15']
Exercise 1. Given text = "the quick brown fox", build words = the list of words → ['the', 'quick', 'brown', 'fox'].
Exercise 2. Given row = "apple,pear,plum", build parts = the list split on commas → ['apple', 'pear', 'plum'].

2. Joining pieces back together

separator.join(list) glues a list of strings into one, putting the separator between each. Note the separator goes first: ", ".join(items).

print(" ".join(["Hello", "world"]))      # Hello world
print("-".join(["2024", "01", "15"]))    # 2024-01-15
print(", ".join(["a", "b", "c"]))        # a, b, c
Exercise 3. Given bits = ["2024", "01", "15"], join them with "-" into date → "2024-01-15".
Exercise 4. Given words = ["learn", "by", "doing"], join them with a space into sentence → "learn by doing".

3. Cleaning up text

Three cleaners you'll use constantly: strip() removes leading/trailing spaces, lower() makes everything lowercase (so "Cat" and "cat" match), and replace(old, new) swaps one substring for another.

print("  Hello World  ".strip())    # "Hello World"
print("SHOUT".lower())             # "shout"
print("a.b.c".replace(".", "/"))   # "a/b/c"
Exercise 5. Given raw = " Hello World ", remove the spaces at both ends into clean → "Hello World".
Exercise 6. Given word = "SHOUT", make it lowercase into quiet → "shout".
Exercise 7. Given path = "a.b.c", replace every "." with "/" into fixed → "a/b/c".

4. Searching inside text

To ask questions about text: len(text.split()) counts words, text.count(x) counts how many times something appears, and x in words checks membership.

text = "the cat sat on the mat"
print(len(text.split()))     # 6  — six words
print(text.count("the"))     # 2  — "the" appears twice
print("cat" in text.split()) # True
Exercise 8. Given text = "one two three four", set word_count to the number of words. Result 4.
Exercise 9. Given word = "banana", set a_count to how many times "a" appears. Result 3.
Exercise 10. Given text = "the cat sat on the mat", set has_dog to whether "dog" is one of the words. Result False.
🔥 Stretch (most common word). Given text = "red blue red green red blue", find the word that appears the most into top. Split into words, count with a dictionary, then pick the biggest. Result "red".
Recap of lesson 18: split() breaks text into a list of pieces (pass a separator like "," for other formats) · sep.join(list) glues a list back into a string · clean with strip() (outer spaces), lower() (case), and replace(old, new) · search with len(text.split()), text.count(x), and x in words · together these normalise messy text into tidy data.

Lesson 1 — Getting started with Python: values, variables and print()

Welcome to your very first lesson. If you've never written a line of code before — perfect, this lesson is written exactly for you. We'll go slowly: understand what programming is, what Python is, and only then type our first lines of code.

1. What is programming? What is Python?

Programming is simply writing a list of instructions for a computer to follow — like writing a recipe: step by step, clear, in order. Computers are fast and precise, but they only do exactly what you tell them and never guess your intent. Learning to program is mostly learning to express ideas very clearly so the machine understands.

Python is a programming language — the vocabulary and grammar for writing those instructions. People pick Python to start because it reads close to plain English, has few confusing symbols, and is used everywhere: web, data analysis, automation, artificial intelligence… Writing print("Hello") in Python is far more readable than in many other languages.

In this course you'll run real Python — the same Python professional developers use — right in your browser, with nothing to install.

2. How learning works at The Dojo

Whenever you see a dark box like the one below, that's where you write code. Under it are two buttons:

  • Run: sends your code to real Python. The first run downloads the Python engine (~10MB), which can take 10–30 seconds — be patient; after that it's instant.
  • Reset: restores the code box to its starting state if you want to start over.

After you click Run, you'll see a result area with two parts:

  • Output: everything your program prints to the screen appears here — it's your program's "screen". This panel always shows, whether your answer is right or wrong.
  • Verdict: Pass if your answer is correct, or Fail with a specific hint (e.g. which variable is wrong, what its value is and what it should be).

You can edit your code and click Run as many times as you like — being wrong is normal and the fastest way to learn.

3. Your first command: print()

A program runs its instructions top to bottom, one at a time. The first and most-used one is print() — it tells the computer to show (display) something on screen.

print("Hello")
print("I am learning Python")

Let's read the line print("Hello") part by part:

  • print — the name of the command (show on screen).
  • ( ) — round parentheses; inside them goes the thing you want to print.
  • "Hello" — a piece of text. In programming, text is called a string and must be wrapped in quotes "...". The quotes tell the computer "this is literal text to print", not a command.

If you forget the quotes — e.g. print(Hello) — the computer errors, because it thinks Hello is the name of some command it doesn't know.

4. Comments with #

Did you notice the line # Type your print command below: in the exercise above? That's a comment. Everything after a # on a line is completely ignored by Python — it's a note for humans to read, not an instruction for the machine to run.

# This is a comment — Python doesn't run this line
print("This line does run")   # a comment can also sit at the end of a line

Comments explain the code to you (and others) reading it later. In exercises we often leave a # line hinting where you should write.

5. Values and data types

Every piece of data in Python has a type. The four foundational ones you meet first:

10          # whole number -> int    (no decimal part)
3.14        # decimal      -> float  (has a decimal point)
"hello"     # text         -> str    (letters in quotes)
True        # true/false   -> bool   (only True or False)

You can ask the computer "what type is this?" with type():

print(type(10))       # <class 'int'>
print(type(3.14))     # <class 'float'>
print(type("hi"))     # <class 'str'>
print(type(True))     # <class 'bool'>

Why do types matter? Because the computer behaves differently per type: 3 + 4 gives 7 (adding numbers), but "3" + "4" gives "34" (joining text). Mixing up types is one of the most common beginner bugs.

6. Variables — named boxes

A variable is a name attached to a value so you can reuse it later. The = sign means assign: take the value on the right and put it in the named box on the left.

age = 15
name = "Minh"
print(name, "is", age, "years old")   # Minh is 15 years old

Variables can be reassigned — the new value replaces the old:

score = 5
score = score + 3     # take old score (5), add 3, store back into score -> 8
print(score)           # 8

Naming rules

  • Only letters, digits and underscore _; must not start with a digit.
  • No spaces. Use snake_case to join words: quantity, user_name.
  • Case-sensitive: age and Age are two different variables.
  • Use meaningful names: price beats x.

7. print() in more detail

print() can print several things at once, separated by commas — the computer inserts a space between them:

name = "Minh"
print("Hello,", name)     # Hello, Minh

You can change the separator with sep, and the line-ending character with end:

print("2024", "09", "18", sep="-")   # 2024-09-18
print("Loading", end="...")           # no newline, then prints "..."

8. Reading input from a user — input()

The input() function pauses the program, waits for the user to type, then returns what they typed. Critically important: input() always returns a string (str), even when the person types a number.

name = input("What's your name? ")
print("Hi", name)

age_str = input("Your age? ")   # e.g. typing "15" -> age_str = "15" (a string!)
print(type(age_str))            # <class 'str'>

Because the result is a string, to do math you must convert it to a number first.

9. Type conversion

int("15")     # 15   (string -> integer)
float("3.5")  # 3.5  (string -> float)
str(15)       # "15" (number -> string)

This is why the line below is a classic logic bug: it joins two strings instead of adding two numbers.

a = input("Number a: ")   # "7"
b = input("Number b: ")   # "3"
print(a + b)              # "73"  (WRONG! string join)
print(int(a) + int(b))    # 10    (RIGHT, convert to int first)

10. Arithmetic operators

7 + 3     # 10   add
7 - 3     # 4    subtract
7 * 3     # 21   multiply
7 / 2     # 3.5  divide (ALWAYS a float)
7 // 2    # 3    floor division (whole part)
7 % 2     # 1    remainder (modulo)
2 ** 10   # 1024 power (2 to the 10)

// and % are very handy: // tells you "how many whole times it divides", % tells you "how much is left over". E.g. turn 100 minutes into hours:minutes → 100 // 60 = 1 hour, 100 % 60 = 40 minutes.

Precedence follows math: ** first, then * / // %, then + -. Use parentheses ( ) to force order:

2 + 3 * 4       # 14  (multiply first)
(2 + 3) * 4     # 20  (parentheses first)

11. Augmented assignment (+=, -=, *=)

When you update a variable using itself, Python has a shorthand — used constantly for counting and accumulating:

score = 5
score += 3     # same as: score = score + 3  -> 8
score *= 2     # same as: score = score * 2  -> 16
score -= 1     # -> 15
print(score)   # 15
Exercise 9. Given diem = 10, use augmented assignment: add 5 (+= 5), then double it (*= 2). Final value stays in diem.

12. Common beginner mistakes

  • Missing quotes: print(hello) → error. Text must be "hello".
  • Confusing = and ==: = assigns, == compares (lesson 3).
  • Adding a string to a number: "Age: " + 20 → error. Use "Age: " + str(20).
  • Forgetting to convert after input(): the result is a string, you can't do math on it directly.

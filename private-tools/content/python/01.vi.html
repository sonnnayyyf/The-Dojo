Bài 1 — Bắt đầu với Python: giá trị, biến và print()

Chào mừng bạn đến với bài học đầu tiên. Nếu bạn chưa từng viết một dòng code nào — hoàn hảo, bài này viết đúng cho bạn. Chúng ta sẽ đi thật chậm: hiểu lập trình là gì, Python là gì, rồi mới từ từ gõ những dòng code đầu tiên.

1. Lập trình là gì? Python là gì?

Lập trình đơn giản là viết ra một danh sách chỉ thị (lệnh) để máy tính làm theo — giống như viết công thức nấu ăn: từng bước, rõ ràng, theo thứ tự. Máy tính rất nhanh và chính xác, nhưng nó chỉ làm đúng những gì bạn bảo, không tự đoán ý bạn. Học lập trình phần lớn là học cách diễn đạt ý tưởng thật rõ ràng để máy hiểu.

Python là một ngôn ngữ lập trình — bộ từ vựng và ngữ pháp để viết các chỉ thị đó. Người ta chọn Python để bắt đầu vì nó gần với tiếng Anh đời thường, ít ký hiệu rối rắm, và được dùng ở khắp nơi: web, phân tích dữ liệu, tự động hóa, trí tuệ nhân tạo… Viết print("Xin chao") trong Python dễ đọc hơn hẳn so với nhiều ngôn ngữ khác.

Trong khóa này bạn sẽ chạy Python thật — chính là Python mà lập trình viên chuyên nghiệp dùng — ngay trong trình duyệt, không phải cài đặt gì cả.

2. Cách học ở The Dojo

Mỗi khi gặp một ô có nền tối như bên dưới, đó là chỗ bạn viết code. Bên dưới ô đó có hai nút:

  • Chạy (Run): gửi code của bạn cho Python chạy thật. Lần chạy đầu tiên trình duyệt tải bộ máy Python (~10MB), có thể mất 10–30 giây — hãy kiên nhẫn; các lần sau chạy tức thì.
  • Đặt lại (Reset): đưa ô code về trạng thái ban đầu nếu bạn muốn làm lại từ đầu.

Sau khi bấm Chạy, bạn sẽ thấy một khung kết quả gồm hai phần:

  • Kết quả in ra (Output): mọi thứ chương trình của bạn in ra màn hình sẽ hiện ở đây — giống như "màn hình" của chương trình. Khung này luôn hiện, dù bài làm đúng hay sai.
  • Kết luận: Đạt nếu bài làm đúng, hoặc Chưa đạt kèm một lời gợi ý cụ thể (ví dụ: biến nào sai, giá trị đang là gì và cần là gì).

Bạn có thể sửa code và bấm Chạy lại bao nhiêu lần tùy thích — sai là chuyện bình thường và là cách học nhanh nhất.

3. Lệnh đầu tiên: print()

Chương trình chạy các lệnh lần lượt từ trên xuống dưới. Lệnh đầu tiên và hay dùng nhất là print() — bảo máy in (hiển thị) một thứ gì đó ra màn hình.

print("Xin chao")
print("Toi dang hoc Python")

Hãy đọc dòng print("Xin chao") theo từng phần:

  • print — tên của lệnh (in ra màn hình).
  • ( ) — cặp ngoặc tròn, bên trong đặt thứ bạn muốn in.
  • "Xin chao" — một đoạn chữ. Trong lập trình, chữ được gọi là chuỗi (string) và bắt buộc đặt trong dấu nháy "...". Dấu nháy cho máy biết "đây là chữ để in nguyên văn", không phải một lệnh.

Nếu quên dấu nháy — ví dụ print(Xin chao) — máy sẽ báo lỗi, vì nó tưởng Xin và chao là tên lệnh nào đó mà nó không biết.

Bài tập 1. Dùng print() in ra đúng dòng chữ Hello Dojo. (Nhớ dấu nháy quanh đoạn chữ.)

Lưu ý: bài tập này kiểm tra thứ bạn in ra màn hình (xem khung Kết quả in ra). Đa số bài sau kiểm tra giá trị của biến — ta sẽ học "biến" ngay bên dưới.

4. Chú thích với dấu #

Bạn có để ý dòng # Go lenh print cua ban o duoi day: ở bài tập trên không? Đó là một chú thích (comment). Mọi thứ sau dấu # trên một dòng sẽ bị Python bỏ qua hoàn toàn — nó là ghi chú dành cho con người đọc, không phải lệnh cho máy chạy.

# Day la chu thich — Python khong chay dong nay
print("Day moi la lenh duoc chay")   # chu thich cung co the year cuoi dong

Chú thích dùng để giải thích code cho chính bạn (và người khác) đọc lại sau này. Trong các bài tập, chúng tôi thường để sẵn một dòng # gợi ý chỗ bạn cần viết.

5. Giá trị và kiểu dữ liệu

Mọi dữ liệu trong Python đều có một kiểu. Bốn kiểu nền tảng bạn gặp đầu tiên:

10          # so nguyen  -> int    (khong co phan thap phan)
3.14        # so thuc    -> float  (co dau cham thap phan)
"xin chao"  # chuoi      -> str    (chu trong dau nhay)
True        # dung/sai   -> bool   (chi True hoac False)

Bạn có thể hỏi máy "đây là kiểu gì?" bằng lệnh type():

print(type(10))       # <class 'int'>
print(type(3.14))     # <class 'float'>
print(type("hi"))     # <class 'str'>
print(type(True))     # <class 'bool'>

Vì sao kiểu lại quan trọng? Vì máy cư xử khác nhau tùy kiểu: 3 + 4 ra 7 (cộng số), nhưng "3" + "4" ra "34" (nối chữ lại với nhau). Nhầm kiểu là một trong những lỗi phổ biến nhất của người mới.

Bài tập 2. Tạo bốn biến: a = số nguyên 42, b = số thực 3.5, c = chuỗi "Python" (viết hoa chữ P), d = giá trị đúng/sai True.

6. Biến — chiếc hộp có tên

Một biến là cái tên gắn với một giá trị, giúp bạn lưu lại để dùng sau. Dấu = nghĩa là gán: lấy giá trị bên phải, bỏ vào chiếc hộp có tên bên trái.

age = 15
name = "Minh"
print(name, "year nay", age, "age")   # Minh year nay 15 age

Biến có thể gán lại — giá trị mới thay giá trị cũ:

score = 5
score = score + 3     # lay score cu (5) cong 3, cat lai vao score -> 8
print(score)          # 8

Quy tắc đặt tên biến

  • Chỉ gồm chữ cái, chữ số và dấu gạch dưới _; không bắt đầu bằng chữ số.
  • Không dấu tiếng Việt, không khoảng trắng. Dùng gach_duoi để nối từ: quantity, user_name.
  • Phân biệt hoa–thường: age và Tuoi là hai biến khác nhau.
  • Đặt tên có nghĩa: price tốt hơn x.
Bài tập 3. Tạo biến quantity = 4 và unit_price = 25000. Tạo biến subtotal bằng tích của chúng (viết phép nhân *, đừng ghi sẵn kết quả).

7. print() kỹ hơn

print() có thể in nhiều thứ một lúc, cách nhau bằng dấu phẩy — máy tự chèn một khoảng trắng giữa chúng:

name = "Minh"
print("Xin chao,", name)     # Xin chao, Minh

Bạn có thể đổi ký tự ngăn cách bằng sep, và ký tự kết thúc dòng bằng end:

print("2024", "09", "18", sep="-")   # 2024-09-18
print("Dang tai", end="...")          # khong xuong dong, in tiep "..."
Bài tập 4. Cho year = 2026, month = 9, day = 18. Dùng print() với sep để in đúng chuỗi 2026/9/18. (Lưu ý: đây là ba biến số, đừng đặt chúng trong dấu nháy.)

8. Nhận dữ liệu từ người dùng — input()

Hàm input() dừng chương trình lại, chờ người dùng gõ, rồi trả về thứ họ gõ. Điều cực kỳ quan trọng: input() luôn trả về một chuỗi (str), kể cả khi người ta gõ số.

name = input("Ten ban la gi? ")
print("Chao", name)

age_str = input("Tuoi cua ban? ")   # vi du go "15" -> age_str = "15" (chuoi!)
print(type(age_str))                 # <class 'str'>

Vì kết quả là chuỗi, muốn tính toán bạn phải ép kiểu sang số trước.

9. Ép kiểu (type conversion)

int("15")     # 15   (chuoi -> so nguyen)
float("3.5")  # 3.5  (chuoi -> so thuc)
str(15)       # "15" (so -> chuoi)

Đây là lý do dòng dưới bị lỗi logic kinh điển: nối hai chuỗi thay vì cộng hai số.

a = input("So a: ")   # "7"
b = input("So b: ")   # "3"
print(a + b)          # "73"  (SAI! noi chuoi)
print(int(a) + int(b))# 10    (DUNG, ep sang int truoc)
Bài tập 5. Cho hai chuỗi a = "7" và b = "3" (giả lập kết quả của input()). Tạo biến total = tổng số học của chúng (kết quả phải là 10, không phải "73").

10. Tính toán — các phép toán số học

7 + 3     # 10   cong
7 - 3     # 4    tru
7 * 3     # 21   nhan
7 / 2     # 3.5  chia (LUON ra float)
7 // 2    # 3    chia lay phan nguyen
7 % 2     # 1    chia lay so du (modulo)
2 ** 10   # 1024 luy thua (2 mu 10)

Hai phép // và % rất hay dùng: // cho biết "chia được bao nhiêu lần trọn vẹn", % cho biết "còn dư bao nhiêu". Ví dụ đổi 100 phút ra giờ:phút → 100 // 60 = 1 giờ, 100 % 60 = 40 phút.

Thứ tự ưu tiên giống toán học: ** trước, rồi * / // %, rồi + -. Dùng ngoặc ( ) khi muốn ép thứ tự:

2 + 3 * 4       # 14  (nhan truoc)
(2 + 3) * 4     # 20  (ngoac truoc)
Bài tập 6. Cho total_minutes = 100. Tính hours = số giờ trọn vẹn và minutes = số phút còn dư (dùng // và % với 60).

11. Gán rút gọn (+=, -=, *=)

Khi cập nhật một biến bằng chính nó, Python có cách viết ngắn gọn — rất hay dùng khi đếm hoặc cộng dồn:

score = 5
score += 3     # giong: score = score + 3  -> 8
score *= 2     # giong: score = score * 2  -> 16
score -= 1     # -> 15
print(score)   # 15
Bài tập 9. Cho diem = 10. Dùng phép gán rút gọn: cộng thêm 5 (+= 5) rồi nhân đôi (*= 2). Kết quả cuối cùng lưu ở diem.

12. Những lỗi thường gặp của người mới

  • Quên dấu nháy: print(xin chao) → lỗi. Chuỗi phải là "xin chao".
  • Nhầm = với ==: = là gán, == là so sánh (học ở bài 3).
  • Cộng chuỗi với số: "Age: " + 20 → lỗi. Phải "Age: " + str(20).
  • Quên ép kiểu sau input(): kết quả là chuỗi, không tính toán trực tiếp được.

Bài sau: làm chủ chuỗi và f-string.

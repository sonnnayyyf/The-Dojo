Bài 9 — Cài đặt: Python + VS Code

Từ đầu khóa đến giờ bạn chạy Python ngay trong trình duyệt. Sân tập đó rất hợp để học vì phản hồi tức thì — nhưng đó không phải nơi các chương trình thật “sống”. Lập trình viên chuyên nghiệp viết mã vào các tệp trên máy của mình, dùng một trình soạn mã đúng nghĩa, rồi chạy các tệp đó bằng Python thật đã cài đặt. Bài này là cây cầu nối từ sân tập sang quy trình thật đó.

Có hai phần. Phần đầu là bước cài đặt ngắn, chỉ làm một lần: cài Python và cài VS Code (trình soạn thảo miễn phí mà đa số lập trình viên Python dùng). Phần sau, và lớn hơn, là một loạt bài tập khởi động chuẩn bị cho đồ án nhỏ ở bài kế tiếp — một trình quản lý công việc (to-do). Bạn vẫn chạy các bài tập này ngay trong trình duyệt để giữ được sự chấm bài tức thì trong lúc luyện những mảnh ghép sắp lắp ráp.

Kể từ đây bài tập về nhà chuyển sang làm trong VS Code thật thay vì chấm tự động trên web — nên làm cho công cụ chạy được là bước đầu quan trọng. Hãy thong thả với phần cài đặt; mọi thứ sau đó đều là list, vòng lặp và chuỗi quen thuộc, hướng tới một mục tiêu: một danh sách công việc chạy được.

1. Chuẩn bị công cụ (cài một lần)

Bạn chỉ làm việc này một lần. Ba bước nhỏ:

BướcLàm gì
1. Cài PythonVào python.org/downloads, tải bản mới nhất, chạy trình cài đặt, và tích “Add Python to PATH” trước khi bấm Install.
2. Cài VS CodeVào code.visualstudio.com, tải và cài Visual Studio Code.
3. Thêm extension PythonMở VS Code → Extensions (biểu tượng ô vuông) → tìm “Python” (của Microsoft) → Install.

Để kiểm tra đã chạy được, mở terminal trong VS Code (menu Terminal → New Terminal) và gõ python --version. Bạn sẽ thấy dạng như Python 3.12.x. Cài đặt chỉ có vậy — phần còn lại của bài là luyện tập.

2. Mã chạy từ một tệp như thế nào

Trong trình duyệt, mã chạy ngay khi bạn bấm ▶. Trên máy bạn, vòng lặp dài hơn một chút nhưng cũng đơn giản: bạn viết mã vào một tệp .py, VS Code đưa tệp đó cho Python, và Python chạy từ trên xuống rồi hiện kết quả trong terminal.

Tin vui: ngôn ngữ Python giống hệt như trong sân tập này. Mọi thứ bạn đã biết — list, vòng lặp, if, f-string — đều hoạt động y như vậy trong một tệp. Vậy nên hãy khởi động với những viên gạch của trình quản lý công việc.

3. Danh sách công việc chỉ là một list các chuỗi

Một app to-do, về bản chất, là một list các chuỗi trong đó mỗi chuỗi là một công việc. Bạn đã biết cách nới rộng list bằng append.

tasks = []
tasks.append("Buy milk")
tasks.append("Call Anna")
print(tasks)   # ['Buy milk', 'Call Anna']
Bài tập 1. Bắt đầu với tasks = [] và append ba công việc theo thứ tự: "Buy milk", "Call Anna", "Wash car". Kết quả ['Buy milk', 'Call Anna', 'Wash car'].
Bài tập 2. Cho tasks = ["Buy milk", "Call Anna"], thêm "Pay bills" vào cuối. Kết quả ['Buy milk', 'Call Anna', 'Pay bills'].

4. Xóa và tìm một công việc

Người dùng cũng hoàn thành hoặc hủy công việc. list.remove(value) xóa phần tử khớp đầu tiên; muốn biết công việc nằm ở đâu, duyệt list và so sánh.

tasks = ["Buy milk", "Call Anna", "Wash car"]
tasks.remove("Call Anna")
print(tasks)                 # ['Buy milk', 'Wash car']
print("Wash car" in tasks)   # True — kiểm tra có mặt
Bài tập 3. Cho tasks = ["Buy milk", "Call Anna", "Wash car"], xóa "Call Anna". Kết quả ['Buy milk', 'Wash car'].
Bài tập 4. Cho tasks = ["Buy milk", "Call Anna", "Wash car"], gán has_call bằng việc "Call Anna" có trong list hay không. Kết quả True.
Bài tập 5. Cho tasks = ["Buy milk", "Call Anna", "Wash car"], tìm chỉ số của "Wash car" bằng vòng lặp và lưu vào pos (bắt đầu pos = -1). Kết quả 2.

5. Hiển thị một menu có đánh số

Con người đếm từ 1, nhưng chỉ số list bắt đầu từ 0 — nên dòng menu cho công việc ở chỉ số i hiện số i + 1. Dựng mỗi dòng bằng f-string.

tasks = ["Buy milk", "Call Anna"]
for i in range(len(tasks)):
    print(f"{i + 1}. {tasks[i]}")
# 1. Buy milk
# 2. Call Anna
chỉ số itasks[i]dòng menu
0"Buy milk"1. Buy milk
1"Call Anna"2. Call Anna
Bài tập 6. Cho tasks = ["Buy milk", "Call Anna", "Wash car"], dựng list lines gồm các chuỗi menu "1. Buy milk", "2. Call Anna", "3. Wash car" (dùng i + 1 và f-string).
Bài tập 7. Cho tasks = ["Buy milk", "Call Anna"], in menu có đánh số (mỗi công việc một dòng, dạng 1. Buy milk). Kiểm tra phần in ra.

6. Đánh dấu công việc đã xong

Một mẹo phổ biến: đánh dấu công việc đã xong bằng cách gắn một nhãn phía trước phần chữ, như "[x] ". Khi đó một công việc là “đã xong” khi nó bắt đầu bằng nhãn ấy (task.startswith("[x] ")).

tasks = ["Buy milk", "Call Anna"]
done = []
for t in tasks:
    done.append("[x] " + t)
print(done)   # ['[x] Buy milk', '[x] Call Anna']
Bài tập 8. Cho tasks = ["Buy milk", "Call Anna", "Wash car"], dựng done trong đó mỗi công việc được gắn tiền tố "[x] " → ['[x] Buy milk', '[x] Call Anna', '[x] Wash car'].
Bài tập 9. Cho tasks = ["[x] Buy milk", "Call Anna", "[x] Wash car"], đếm bao nhiêu công việc đã xong (bắt đầu bằng "[x] ") vào done_count. Kết quả 2.

7. Một bản tóm tắt nhỏ

Mảnh ghép cuối trước đồ án nhỏ: một dòng tóm tắt. Đếm tổng số và số công việc đã xong, rồi ghép thành một câu rõ ràng.

tasks = ["[x] Buy milk", "Call Anna", "[x] Wash car"]
total = len(tasks)
done = 0
for t in tasks:
    if t.startswith("[x] "):
        done += 1
print(f"{done} of {total} tasks done")   # 2 of 3 tasks done
Bài tập 10. Cho tasks = ["[x] Buy milk", "Call Anna", "[x] Wash car", "Pay bills"], dựng chuỗi summary = "2 of 4 tasks done" dùng len, một vòng lặp và f-string.
🔥 Nâng cao (bản báo cáo trạng thái). Cho tasks = ["[x] Buy milk", "Call Anna", "[x] Wash car"], dựng list report các dòng "N. STATUS name" trong đó STATUS là DONE nếu công việc bắt đầu bằng "[x] " (và tên đã bỏ nhãn đó bằng task[4:]) hoặc TODO nếu ngược lại → ['1. DONE Buy milk', '2. TODO Call Anna', '3. DONE Wash car'].
Tóm tắt bài 9: cài Python (tích “Add to PATH”) + VS Code + extension Python · kiểm tra bằng python --version · một chương trình là tệp .py mà Python chạy từ trên xuống · danh sách công việc là một list các chuỗi: nới rộng bằng append, xóa bằng remove, kiểm tra bằng in · đánh số menu bằng i + 1 · đánh dấu xong bằng tiền tố "[x] " và kiểm tra bằng startswith. Bài sau: lắp các mảnh này thành đồ án nhỏ trình quản lý công việc (to-do).

🏠 Bài tập về nhà

Kể từ bài này, bài tập về nhà được làm trong VS Code thật trên máy bạn (không chấm tự động ở đây). Tạo một thư mục cho khóa học và một tệp tasks.py, rồi hoàn thành các phần dưới. Chạy tệp sau mỗi bước bằng nút ▶ Run hoặc python tasks.py trong terminal.

  1. Chào công cụ. Trong tasks.py, in "My task manager". Chạy tệp và xác nhận bạn thấy dòng đó trong terminal.
  2. Hiện danh sách. Tạo một list 3 công việc và in chúng thành menu có đánh số (1. ..., 2. ..., 3. ...) dùng vòng lặp for và i + 1.
  3. Thêm và xóa. In list, rồi append một công việc mới và remove một công việc ban đầu, in lại list để thấy thay đổi.
  4. 🔥 Nâng cao — tóm tắt. Đánh dấu một công việc đã xong bằng tiền tố "[x] ", rồi in một dòng tóm tắt dạng "1 of 3 tasks done" bằng cách đếm các công việc startswith("[x] ").

Lesson 5 — Lists & indexing

So far each variable holds one value. But real life is full of collections: a list of students, a shopping cart, a class's scores. A list (array) is how Python stores many values in one variable — and the index is how you reach each element. This is one of the most important skills in the whole course.

1. Creating a list

Put values inside square brackets [ ], separated by commas:

diem = [8, 6, 9, 7]
ten = ["An", "Binh", "Chi"]
rong = [1, "hai", 3.0, True]   # types can mix, but usually keep them the same
print(diem)
print(len(diem))               # 4 — number of elements
Exercise 1. Create a list nums of four numbers 10, 20, 30, 40. Create count = the number of elements (use len).

2. Indexing — reaching each element

Just like strings: each element has an index counting from 0. Negative indexes count back from the end.

nums = [10, 20, 30, 40]
print(nums[0])    # 10 — first element
print(nums[2])    # 30
print(nums[-1])   # 40 — last element
# print(nums[4])  # ERROR: IndexError — there is no index 4
Exercise 2. Given nums = [10, 20, 30, 40], take the first element into first and the last into last (use indexing).

3. Slicing a list

Like strings: lst[start:stop] takes from start up to just before stop, returning a new list.

nums = [10, 20, 30, 40, 50]
print(nums[1:3])   # [20, 30]
print(nums[:2])    # [10, 20]
print(nums[-2:])   # [40, 50]
Exercise 3. Given nums = [10, 20, 30, 40], take the first two elements into first_two.

4. Lists are MUTABLE

Unlike strings, you are allowed to change an element by assigning to its index:

nums = [10, 20, 30]
nums[0] = 99
print(nums)        # [99, 20, 30]
Exercise 4. Given nums = [10, 20, 30, 40], change the first element to 99 (assign to nums[0]).

5. Adding & removing elements

cart = ["ao", "quan"]
cart.append("mu")      # add to the END -> ["ao","quan","mu"]
cart.insert(0, "giay") # insert at position 0
print(cart)            # ["giay","ao","quan","mu"]
taken = cart.pop()     # take & remove the LAST -> "mu"
cart.remove("ao")      # remove the element equal to "ao"
print(cart, taken)
Exercise 5. Given fruits = ["apple", "banana"], add "cherry" to the end (use append).
Exercise 6. Given colors = ["red", "green", "blue"], use pop() to take the last element into removed (the list is left with 2 elements).

6. Membership with in

mau = ["red", "green"]
print("red" in mau)      # True
print("black" in mau)    # False
Exercise 7. Given colors = ["red", "green"], create has_red = True if "red" is in the list.

7. Handy built-in functions

diem = [8, 6, 9, 7]
print(sum(diem))    # 30 — total
print(max(diem))    # 9  — largest
print(min(diem))    # 6  — smallest
print(len(diem))    # 4  — count
Exercise 8. Given scores = [8, 6, 9, 7], create total = the sum (use sum) and best = the highest score (use max).

8. A few tips & mixed practice

Two handy list tricks:

  • Join two lists with +: [1, 2] + [3, 4] → [1, 2, 3, 4].
  • Reverse with the slice [::-1]: [1, 2, 3][::-1] → [3, 2, 1].
a = [1, 2]
b = [3, 4]
print(a + b)             # [1, 2, 3, 4]
print([1, 2, 3][::-1])   # [3, 2, 1]
Exercise 9. Given nums = [4, 2, 7, 1], create avg = the average (sum divided by count) → 3.5.
Exercise 10. Given a = [1, 2] and b = [3, 4], create combined = the two lists joined → [1, 2, 3, 4].
Exercise 11. Given nums = [1, 2, 3, 4], create reversed_list = the reversed list (use [::-1]) → [4, 3, 2, 1].

Recap of lesson 5: [ ] makes a list · len() counts · index from 0, negatives from the end, out of range → IndexError · [a:b] slices into a new list · lists are mutable: lst[i] = x · .append/.insert/.pop/.remove · in tests membership · sum/max/min/len. Next: the for loop to visit every element.

Lesson 7 — while loops, break & continue

The for loop is perfect when you know in advance what you'll loop over: a list, a range. But real life is full of situations where you don't know how many times: "keep asking for the password until it's right", "keep halving until it's below 1", "loop until the user types 'quit'". For those, we have the while loop.

The core difference: for loops over a collection, while while loops on a condition — "keep going as long as the condition is true". That power comes with a trap: if the condition never becomes false, the loop runs forever. This lesson teaches you to use while safely, along with the two loop "switches", break and continue.

1. When for isn't enough

Suppose you want to know: how many times do you double 1 before it passes 100? You don't know the answer (the number of times) up front, so you can't write a range. You only know the stopping condition: "stop once it passes 100". That's when you reach for while.

2. The structure of a while loop

n = 5
while n > 0:          # loop AS LONG AS n > 0 is true
    print(n)
    n -= 1            # you MUST change n, or it loops forever
print("Done!")

Read it as: "as long as n > 0, run the indented block". Three parts you need:

  • A control variable initialized before the loop (n = 5).
  • A condition after while — the loop runs while it's true, stops when false.
  • Inside the body, a line that moves the condition toward false (n -= 1). This is the easiest line to forget.

3. How the machine runs a while loop

Before each pass, the machine checks the condition. True → run the body, then check again. False → exit immediately (it may run the body zero times if the condition is false from the start).

Trace n in the example above: 5 (print) → 4 (print) → 3 (print) → 2 (print) → 1 (print) → 0 (the condition 0 > 0 is false → exit).

4. The trap: infinite loops

If the condition never becomes false, the program hangs forever. This is the most common while bug — usually caused by forgetting to update the control variable.

# DO NOT RUN THIS — infinite loop!
n = 5
while n > 0:
    print(n)      # forgot n -= 1  ->  n stays 5  ->  loops forever

Golden rule: every time you write a while, immediately ask yourself "what makes this condition false, and is that guaranteed to happen?"

5. break — leave the loop immediately

break stops the loop right there, skipping all remaining passes. Very useful for finding the first element that matches a condition and then stopping — no need to walk the rest.

nums = [3, 7, 4, 9, 2]
first_even = None
for n in nums:
    if n % 2 == 0:
        first_even = n
        break            # found it -> exit, don't check 9, 2
print(first_even)        # 4

6. continue — skip the rest of this pass

continue jumps straight to the next pass, skipping the remaining lines of the current one. Use it to "skip over" elements you don't want to process.

nums = [3, -1, 4, -2, 5]
total = 0
for n in nums:
    if n < 0:
        continue         # negative -> skip, go to next pass
    total += n
print(total)             # 3 + 4 + 5 = 12

7. The "process until done" pattern

A very common shape: transform a value repeatedly until it reaches a target state. For example the Collatz sequence: if even halve it, if odd do 3n + 1, repeat until it reaches 1.

n = 6
steps = 0
while n != 1:
    if n % 2 == 0:
        n = n // 2
    else:
        n = 3 * n + 1
    steps += 1
print(steps)    # 8 steps: 6->3->10->5->16->8->4->2->1
Exercise 8. Given n = 6, count the steps for the Collatz sequence to bring n to 1 into steps (even → halve, odd → 3n + 1). Result 8.

Recap of lesson 7: while condition: loops as long as the condition is true · always include a line that moves the condition toward false, or you get an infinite loop · break exits the loop now · continue skips the rest and goes to the next pass · while True: ... break when the stopping condition is in the middle of the body.

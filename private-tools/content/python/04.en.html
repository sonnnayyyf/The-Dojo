Lesson 4 — Boolean logic & nested conditions

Last lesson you made decisions with one condition. Real life is messier: "at least 18 and has a license", "weekend or holiday". This lesson covers combining conditions and nesting them.

1. Three logical operators: and, or, not

  • and — true when both sides are true.
  • or — true when at least one side is true.
  • not — flips it: not True → False.
print(True and False)   # False — needs BOTH true
print(True or False)    # True  — needs just ONE true
print(not True)         # False — flipped

2. Truth table (see it, remember it)

ABA and BA or B

FalseTrueFalseTrue
FalseFalseFalseFalse

Memory tip: and is picky (true only when everything is true), or is easy-going (one true is enough).

age = 25
has_ticket = True
if age >= 18 and has_ticket:
    print("Come into the cinema")

3. Chained comparisons: 0 <= x <= 100

Python lets you write ranges compactly, like in math. Handy for checking a value is within a valid range.

score = 75
print(0 <= score <= 100)   # True — score is in [0, 100]
# same as: score >= 0 and score <= 100

5. Nested conditions (nested if)

You can put an if inside another if — each nesting level indents 4 more spaces. Use it when the second question only makes sense after the first is true.

score = 8
attendance = True
if score >= 8:
    if attendance:
        scholarship = "Full scholarship"
    else:
        scholarship = "Review attendance"
else:
    scholarship = "Score too low"
print(scholarship)    # Full scholarship

When to nest vs. use and? If you just need "both true", and is cleaner. Nest when each level needs its own handling (like above: score high enough but low attendance still gets its own branch).

6. Boolean variables as flags

Storing a condition's result in a bool variable makes code much more readable:

age = 20
income = 8
loan_ok = age >= 18 and income >= 5
if loan_ok:
    print("Loan approved")

7. "Falsy" values & shortcuts

In a condition, some values count as false (falsy) even though they aren't False: the number 0, the empty string "", an empty list [], and None. Everything else is truthy.

name = ""
if name:
    print("Has a name")
else:
    print("No name yet")   # runs, because "" is falsy

This lets you write if name: instead of if name != "":.

Exercise 9. Given cart = [] (an empty list), create is_empty = True if the cart is empty (hint: not cart — an empty list is falsy).

8. Common mistakes

  • Using &&, ||, ! like other languages — Python uses the words and, or, not.
  • Forgetting and is "pickier" than or: when mixing both, use parentheses for clarity: (a and b) or c.
  • Nesting too deep (3–4 levels of if) → hard to read; often you can merge with and or split into functions (later lesson).

Bài 17 — Set & sắp xếp cơ bản

Hai nhu cầu hằng ngày xuất hiện liên tục khi bạn xử lý dữ liệu thật: loại bỏ trùng lặp, và sắp xếp mọi thứ theo thứ tự. Python có một công cụ gọn cho mỗi việc. Một set là một tập hợp tự động chỉ giữ các giá trị duy nhất — hoàn hảo cho câu "có bao nhiêu thứ khác nhau ở đây?". Và sorted() nhận bất kỳ list nào rồi trả về một bản sao đã sắp gọn gàng.

Trên đường đi bạn sẽ gặp ba hàm dựng sẵn nhỏ xíu mà bạn sẽ dùng mãi: min, max, và sum. Cùng với set và sắp xếp, chúng biến một đống số thành câu trả lời — nhỏ nhất, lớn nhất, tổng, thứ hạng — chỉ trong một dòng.

Bài này giữ đúng mức căn bản: ta sắp xếp bằng sorted() thường và reverse=True. (Thứ tự sắp xếp tùy chỉnh bằng key sẽ có ở khóa Trung cấp.)

1. Set: các giá trị duy nhất

Một set dùng dấu ngoặc nhọn như dict, nhưng chứa từng giá trị đơn, không phải cặp. Sức mạnh của nó: âm thầm bỏ đi trùng lặp. Biến một list thành set là cách chuẩn để tìm các phần tử khác nhau.

nums = [1, 2, 2, 3, 3, 3]
unique = set(nums)
print(unique)        # {1, 2, 3}
print(len(unique))   # 3  — ba giá trị khác nhau
Bài tập 1. Cho nums = [1, 2, 2, 3, 3, 3], gán distinct bằng số giá trị khác nhau. Kết quả 3. (Dùng set và len.)
Bài tập 2. Cho tags = {"python", "sql", "qa"}, gán has_sql bằng việc "sql" có trong set hay không. Kết quả True. (Kiểm tra thành viên trên set rất nhanh.)

2. Kết hợp các set

Các set có thể kết hợp như trong toán học: | là hợp (union) (mọi thứ trong một trong hai), & là giao (intersection) (chỉ những gì có ở cả hai).

a = {1, 2, 3}
b = {2, 3, 4}
print(a | b)   # {1, 2, 3, 4}  — hợp
print(a & b)   # {2, 3}        — có ở cả hai
Bài tập 3. Cho a = {1, 2, 3} và b = {2, 3, 4}, dựng combined = hợp của chúng → {1, 2, 3, 4}.
Bài tập 4. Với cùng a và b, dựng shared = các giá trị có ở cả hai → {2, 3}.

3. Sắp xếp với sorted()

sorted(list) trả về một list mới theo thứ tự tăng dần — nó không đổi list gốc. Thêm reverse=True để giảm dần. Nó chạy được với số và, theo thứ tự bảng chữ cái, với chuỗi.

nums = [3, 1, 2]
print(sorted(nums))               # [1, 2, 3]
print(sorted(nums, reverse=True)) # [3, 2, 1]
print(sorted(["banana", "apple", "cherry"]))  # ['apple', 'banana', 'cherry']
Bài tập 5. Cho nums = [3, 1, 2], dựng ordered = các số sắp tăng dần → [1, 2, 3].
Bài tập 6. Cho nums = [3, 1, 2], dựng desc = các số sắp từ lớn tới nhỏ → [3, 2, 1]. (Dùng reverse=True.)
Bài tập 7. Cho words = ["banana", "apple", "cherry"], dựng alpha = các từ theo thứ tự bảng chữ cái → ['apple', 'banana', 'cherry'].

4. min, max, sum

Ba hàm dựng sẵn trả lời những câu hỏi thường gặp nhất về một list số, mỗi câu chỉ một từ.

nums = [4, 2, 8, 6]
print(min(nums))   # 2
print(max(nums))   # 8
print(sum(nums))   # 20
Bài tập 8. Cho nums = [4, 2, 8, 6], gán lowest, highest, và total dùng min, max, và sum. Kết quả 2, 8, 20.
Bài tập 9. Cho nums = [3, 1, 2, 3, 1], dựng unique_sorted = các giá trị khác nhau theo thứ tự tăng dần → [1, 2, 3]. (Kết hợp set và sorted.)
🔥 Nâng cao (ba giá trị lớn nhất). Cho nums = [5, 2, 8, 1, 9, 3], dựng top3 = ba giá trị lớn nhất, lớn nhất trước → [9, 8, 5]. (Sắp giảm dần, rồi lấy ba cái đầu bằng [:3].)
Tóm tắt bài 17: một set chỉ giữ các giá trị duy nhất — set(list) bỏ trùng lặp, kiểm tra thành viên (in) nhanh, và | / & cho hợp / giao · sorted(list) trả về list tăng dần mới, reverse=True để giảm dần, và chạy với chuỗi theo bảng chữ cái · min, max, sum trả lời nhỏ nhất / lớn nhất / tổng trong một từ · kết hợp chúng (ví dụ sorted(set(...))) để có kết quả duy nhất, có thứ tự. Bài sau: bộ công cụ xử lý văn bản — tách, ghép và làm sạch chuỗi. (Thứ tự sắp xếp tùy chỉnh bằng key có ở Python Trung cấp.)

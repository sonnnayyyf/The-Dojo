Lesson 11 — Dictionaries: labelled data

A list is great when order and position matter — task 1, task 2, task 3. But very often you don't want to remember positions; you want to look things up by name. What's Anna's phone number? What's the price of this book? How many times did the word "error" appear? For questions like these, counting on your fingers to index number 7 is the wrong tool.

Python's answer is the dictionary (dict): a collection that maps a key (the label) to a value (the data). Instead of contacts[2] you write contacts["Anna"]. A dictionary is like a real dictionary or a contact card: you look up a word (the key) to get its meaning (the value).

Dictionaries are one of the most used tools in all of Python — configuration, records, counts, JSON data from the web, and the fields of almost any "thing" (a user, a product, a task) are all dictionaries. Learn them well and a huge amount of real code suddenly makes sense.

1. Creating and reading a dictionary

You write a dict with curly braces {} and key: value pairs. You read a value by putting its key in square brackets.

person = {"name": "Anna", "age": 30, "city": "Hanoi"}
print(person["name"])   # Anna
print(person["age"])    # 30
Exercise 1. Create a dictionary person with keys "name" → "Anna", "age" → 30, and "city" → "Hanoi".

2. Adding and updating values

Assigning to a key sets its value. If the key already exists it's updated; if it's new the pair is added.

product = {"name": "Book", "price": 100}
product["price"] = 120        # update an existing key
product["stock"] = 5          # add a new key
print(product)   # {'name': 'Book', 'price': 120, 'stock': 5}
Exercise 3. Given product = {"name": "Book", "price": 100}, change the price to 120. Result {'name': 'Book', 'price': 120}.
Exercise 4. Given product = {"name": "Book", "price": 120}, add a new key "stock" with value 5. Result {'name': 'Book', 'price': 120, 'stock': 5}.

3. Checking keys safely

Reading a key that doesn't exist is an error. Use in to check first, or .get(key, default) to read safely with a fallback value.

person = {"name": "Anna", "age": 30}
print("age" in person)              # True
print("email" in person)            # False
print(person.get("email", "N/A"))   # N/A  (no crash)
Exercise 5. Given person = {"name": "Anna", "age": 30}, set has_email to whether "email" is a key. Result False.
Exercise 6. Given contact = {"name": "Anna", "city": "Hanoi"}, read the phone into phone using .get with a default of "unknown" (there is no phone key). Result "unknown".

4. Looping over a dictionary

Looping a dict gives you its keys. Use .values() for the values and .items() to get both key and value together.

scores = {"Anna": 3, "Ben": 5, "Cara": 2}
total = 0
for value in scores.values():
    total += value
print(total)   # 10

for name, value in scores.items():
    print(f"{name}: {value}")
Exercise 7. Given scores = {"a": 3, "b": 5, "c": 2}, add up all the values into total. Result 10.
Exercise 8. Given prices = {"coffee": 30, "tea": 25, "cake": 60}, count how many items cost more than 40 into expensive. Result 1.
Exercise 9. Given menu = {"coffee": 30, "tea": 25}, build a list lines of "key: value" strings using .items() → ['coffee: 30', 'tea: 25'].

5. The counting pattern

One of the most useful dictionary tricks: counting. Walk a list, and for each item add 1 to its entry — using .get(item, 0) so a brand-new item starts from 0.

words = ["red", "blue", "red", "green", "red"]
counts = {}
for w in words:
    counts[w] = counts.get(w, 0) + 1
print(counts)   # {'red': 3, 'blue': 1, 'green': 1}
Exercise 10. Given items = ["a", "b", "a", "c", "a", "b"], build a counts dictionary of how many times each appears → {'a': 3, 'b': 2, 'c': 1}.
🔥 Stretch (word frequency). Given the sentence text = "red blue red green blue red", split it into words and build a counts dictionary of word → count → {'red': 3, 'blue': 2, 'green': 1}. (Use text.split().)
Recap of lesson 11: a dictionary maps keys to values — look up by label, not position · create with {"k": v}, read with d["k"] · assign to add or update · check with in or read safely with .get(key, default) · loop .values(), .items() · the counting pattern d[x] = d.get(x, 0) + 1.

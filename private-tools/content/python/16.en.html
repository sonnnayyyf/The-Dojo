Lesson 16 — Tuples, unpacking & enumerate

You've quietly been using tuples already — every time a function returned two values, or you wrote (3, 4). A tuple is like a list, but fixed: once made, you can't change its contents. That sounds like a limitation, but it's exactly what you want for things that come in a set shape and shouldn't be edited by accident — a coordinate (x, y), an RGB colour, a (name, score) pair.

Alongside tuples come two everyday conveniences: unpacking (splitting a tuple straight into named variables) and enumerate (looping over a list while getting each item's index for free). Both make your code shorter and much easier to read than juggling index numbers by hand.

These are small tools, but you'll reach for them in almost every program from here on. Let's make them second nature.

1. Tuples: fixed groups of values

Write a tuple with commas, usually inside parentheses. You read it by index just like a list — but you can't reassign its items.

point = (3, 4)
print(point[0])     # 3
print(point[1])     # 4
# point[0] = 9      # ERROR — tuples are immutable
Exercise 1. Create a tuple rgb holding 255, 128, 0 (in that order). So rgb is (255, 128, 0).

2. Unpacking a tuple

Assign a tuple to several names at once and Python hands each value to its own variable. Cleaner than point[0], point[1] everywhere.

point = (3, 4)
x, y = point         # unpack
print(x, y)          # 3 4

a, b = 1, 2
a, b = b, a          # swap in one line!
print(a, b)          # 2 1
Exercise 2. Given point = (3, 4), unpack it into x and y, then set s to their sum. So s is 7.
Exercise 3. Given a = 1 and b = 2, swap them using unpacking so that a becomes 2 and b becomes 1.

3. enumerate: index and value together

You often need both the position and the item while looping. Instead of range(len(...)) and manual indexing, enumerate hands you both. Add start=1 to count from 1.

tasks = ["Buy milk", "Call Anna"]
for i, task in enumerate(tasks, start=1):
    print(f"{i}. {task}")
# 1. Buy milk
# 2. Call Anna
Exercise 4. Given tasks = ["Buy milk", "Call Anna", "Wash car"], build a list lines of "N. task" strings using enumerate(tasks, start=1) → ['1. Buy milk', '2. Call Anna', '3. Wash car'].
Exercise 5. Given names = ["a", "b", "c"], use enumerate to find the index of "b" into pos (start pos = -1). Result 1.

4. Looping over pairs

When a list holds tuples, unpack them right in the for line. This is exactly how you loop a dictionary's .items() too.

pairs = [("a", 1), ("b", 2), ("c", 3)]
total = 0
for letter, number in pairs:
    total += number
print(total)   # 6
Exercise 6. Given pairs = [("a", 1), ("b", 2), ("c", 3)], add up the second value of each pair into total by unpacking in the loop. Result 6.

5. zip: pairing two lists

zip walks two lists side by side, giving tuples of matching items. Perfect for combining related data — and dict(zip(...)) turns two lists into a dictionary.

names = ["Anna", "Ben"]
ages = [30, 25]
paired = list(zip(names, ages))
print(paired)              # [('Anna', 30), ('Ben', 25)]
print(dict(zip(names, ages)))   # {'Anna': 30, 'Ben': 25}
Exercise 7. Given names = ["a", "b"] and ages = [20, 30], build paired = a list of tuples pairing them → [('a', 20), ('b', 30)]. (Use zip and list.)
Exercise 8. Given the same names and ages, build a dictionary ages_by_name mapping each name to its age → {'a': 20, 'b': 30}. (Use dict(zip(...)).)
Exercise 9. Given words = ["x", "y", "z"], build a dictionary indexed mapping each index to its word → {0: 'x', 1: 'y', 2: 'z'}. (Use enumerate.)
🔥 Stretch (top scorer). Given scores = [("Anna", 85), ("Ben", 92), ("Cara", 78)], find the name with the highest score into winner by unpacking each pair in a loop. Result "Ben".
Recap of lesson 16: a tuple is an ordered, immutable group — great for fixed records like (x, y) · unpack a tuple into names (x, y = point) and swap in one line (a, b = b, a) · enumerate gives index + value in a loop (for i, v in enumerate(items, start=1)) · unpack tuples right in the for line · zip pairs two lists, and dict(zip(...)) builds a dictionary.

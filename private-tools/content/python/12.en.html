Lesson 12 — Lists of dictionaries: real-world data

A single dictionary describes one thing: one person, one product, one task. But real programs deal with many things — a list of contacts, a cart full of products, a whole to-do list. The natural shape for that is a list of dictionaries: an ordered collection where every item is a record with the same fields. This is, quite literally, a table — rows and columns — and it's how almost all real data arrives, including JSON from the web.

Once you can walk a list of dictionaries, you can do the things every app and every data job needs: list records, filter them ("only adults", "only unfinished tasks"), add them up ("total price"), and find extremes ("the most expensive item"). It's the same loop skills you already have, now reaching one level deeper.

In this lesson you'll build exactly those moves, and finish by upgrading our task manager: instead of tagging strings with "[x] ", each task becomes a tidy dictionary with a name and a done field.

1. A list of records is a table

To reach a field you drill in twice: first pick the record by its position, then the field by its key.

products = [
    {"name": "Book", "price": 100},
    {"name": "Pen", "price": 20},
]
print(products[0])            # {'name': 'Book', 'price': 100}  (a whole record)
print(products[0]["name"])    # Book                            (one field)
print(products[1]["price"])   # 20
Exercise 1. Given products = [{"name": "Book", "price": 100}, {"name": "Pen", "price": 20}], read the price of the second product into p. Result 20.
Exercise 2. Given the same products, build a list names of every product's name → ['Book', 'Pen'].

2. Filtering records

Loop the records and keep the ones that pass a test. This is how every "show me only…" feature works.

people = [
    {"name": "A", "age": 20},
    {"name": "B", "age": 15},
    {"name": "C", "age": 30},
]
adults = []
for person in people:
    if person["age"] >= 18:
        adults.append(person["name"])
print(adults)   # ['A', 'C']
Exercise 3. Given people = [{"name": "A", "age": 20}, {"name": "B", "age": 15}, {"name": "C", "age": 30}], build adults = the names of people aged 18 or older → ['A', 'C'].

3. Adding up a field

To total a column, loop the records and add one field each time.

cart = [
    {"name": "Book", "price": 100},
    {"name": "Pen", "price": 20},
    {"name": "Cup", "price": 50},
]
total = 0
for item in cart:
    total += item["price"]
print(total)   # 170
Exercise 4. Given cart = [{"name": "Book", "price": 100}, {"name": "Pen", "price": 20}, {"name": "Cup", "price": 50}], add up all the prices into total. Result 170.
Exercise 5. Given the same cart, count how many items cost more than 40 into pricey. Result 2.

4. Finding the extreme record

To find the biggest (or smallest), keep a "best so far" and update it whenever you see something better. Start it at the first record.

cart = [{"name": "Book", "price": 100}, {"name": "Pen", "price": 20}, {"name": "Cup", "price": 50}]
best = cart[0]
for item in cart:
    if item["price"] > best["price"]:
        best = item
print(best["name"])   # Book
Exercise 6. Given cart = [{"name": "Book", "price": 100}, {"name": "Pen", "price": 20}, {"name": "Cup", "price": 50}], find the name of the most expensive item into top_name. Result "Book".
Exercise 7. Given cart = [{"name": "Book", "price": 100}], add a new record {"name": "Bag", "price": 80} to the end. Result [{'name': 'Book', 'price': 100}, {'name': 'Bag', 'price': 80}].

5. Updating a record inside the list

Loop until you find the record you want, then change one of its fields. Editing the record edits it right there in the list.

tasks = [
    {"name": "Buy milk", "done": True},
    {"name": "Call Anna", "done": False},
]
for task in tasks:
    if task["name"] == "Call Anna":
        task["done"] = True
print(tasks[1])   # {'name': 'Call Anna', 'done': True}
Exercise 8. Given tasks = [{"name": "Buy milk", "done": True}, {"name": "Call Anna", "done": False}], mark the task named "Call Anna" as done (done = True). The second record should become {'name': 'Call Anna', 'done': True}.

6. Nested data

Records can hold lists, and those lists can hold more records. You just drill in step by step. Here an order contains a list of item records.

order = {"id": 1, "items": [{"name": "Book", "qty": 2}, {"name": "Pen", "qty": 5}]}
total_qty = 0
for item in order["items"]:
    total_qty += item["qty"]
print(total_qty)   # 7
Exercise 9. Given order = {"id": 1, "items": [{"name": "Book", "qty": 2}, {"name": "Pen", "qty": 5}]}, add up the quantities of all items into total_qty. Result 7.
Exercise 10. Given people = [{"name": "A", "age": 20}, {"name": "B", "age": 15}, {"name": "C", "age": 30}], compute the average age into avg, rounded to 1 decimal place. (20 + 15 + 30) / 3 = 21.7.
🔥 Stretch (task summary). Given tasks = [{"name": "a", "done": True}, {"name": "b", "done": False}, {"name": "c", "done": True}], build a summary dictionary counting the records → {"total": 3, "done": 2, "pending": 1}.
Recap of lesson 12: a list of dictionaries is a table of records — the shape of real-world data · drill in with data[i]["field"] · loop the records to list, filter, total, count and find the max · add a record with append({...}) · update by finding the record and changing a field · nested data (a dict holding a list of dicts) is just drilling one more level.

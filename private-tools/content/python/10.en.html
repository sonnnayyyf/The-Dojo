Lesson 10 — Mini project: a task manager

You now know the core building blocks of Python: variables, strings, conditions, lists, and loops. On their own each one is small — but real programs are just these blocks assembled to do something useful. In this lesson you stop learning pieces and start building a whole thing: a small task manager, the kind of app developers put together all the time.

This is a checkpoint lesson. Instead of one new idea, you'll combine everything so far, one feature at a time: store tasks, add them, list them with checkboxes, mark them done, remove them, and print a summary. Each exercise builds one real feature of the app — and by the end they click together into a program that actually works.

A real task manager would wrap this in a menu loop that reads what the user types. In the browser we can't read live input, so here we build and test the logic — the hard, important part — on lists we control. Then your homework is to wrap that exact logic in a real menu loop inside VS Code.

1. The plan: what we're building

Our task manager keeps a list of task strings. A task is "done" when it starts with the tag "[x] " (you met this in Lesson 9). Everything the app does is one of a few simple operations on that list.

tasks = ["[x] Buy milk", "Call Anna", "Wash car"]
# "[x] " in front means done. No tag means still to do.
print(tasks[0].startswith("[x] "))   # True  -> done
print(tasks[1].startswith("[x] "))   # False -> to do

2. Adding tasks (and ignoring empty ones)

When a user adds a task, a good app ignores blank input. We use .strip() to remove spaces and only keep tasks that still have text.

adds = ["Buy milk", "   ", "Call Anna"]
tasks = []
for a in adds:
    if a.strip() != "":
        tasks.append(a.strip())
print(tasks)   # ['Buy milk', 'Call Anna']
Exercise 1. Given adds = ["Buy milk", "", "Call Anna", " ", "Wash car"], build tasks by appending only the non-empty entries (use .strip()). Result ['Buy milk', 'Call Anna', 'Wash car'].

3. Listing tasks with numbers and checkboxes

The user needs to see the list. We show each task with its number (i + 1) and a checkbox: [x] if done, [ ] if not. For a done task we also strip the "[x] " tag off the name so it reads cleanly.

tasks = ["[x] Buy milk", "Call Anna"]
for i in range(len(tasks)):
    t = tasks[i]
    if t.startswith("[x] "):
        print(f"{i + 1}. [x] {t[4:]}")
    else:
        print(f"{i + 1}. [ ] {t}")
# 1. [x] Buy milk
# 2. [ ] Call Anna
Exercise 2. Given tasks = ["[x] Buy milk", "Call Anna", "Wash car"], build a list lines of display strings: done tasks as "N. [x] name" (tag removed) and others as "N. [ ] name" → ['1. [x] Buy milk', '2. [ ] Call Anna', '3. [ ] Wash car'].
Exercise 3. Given the same tasks, print the numbered checkbox list (one line each, exactly like the example above). Check the printed output.

4. Marking a task done

To mark task number n done, put the "[x] " tag in front of it — but only if it isn't already done, so we never end up with "[x] [x] ".

tasks = ["Buy milk", "Call Anna"]
n = 1                       # mark the 1st task (index n-1 = 0)
if not tasks[n - 1].startswith("[x] "):
    tasks[n - 1] = "[x] " + tasks[n - 1]
print(tasks)   # ['[x] Buy milk', 'Call Anna']
Exercise 4. Given tasks = ["Buy milk", "Call Anna", "Wash car"] and n = 2, mark task number n done by adding "[x] " in front (only if not already done). Result ['Buy milk', '[x] Call Anna', 'Wash car'].
Exercise 5. Given task = "[x] Buy milk", toggle it into toggled: if it starts with "[x] " remove that tag, otherwise add it. Here it should become "Buy milk".

5. Removing a task

To delete task number n, remove the item at index n - 1. list.pop(index) does exactly that.

tasks = ["Buy milk", "Call Anna", "Wash car"]
n = 2
tasks.pop(n - 1)           # remove the 2nd task
print(tasks)   # ['Buy milk', 'Wash car']
Exercise 6. Given tasks = ["Buy milk", "Call Anna", "Wash car"] and n = 3, remove task number n. Result ['Buy milk', 'Call Anna'].

6. Filtering: what's still to do

A useful view is "only the tasks I still have to do" — the ones not starting with "[x] ".

tasks = ["[x] Buy milk", "Call Anna", "[x] Wash car", "Pay bills"]
pending = []
for t in tasks:
    if not t.startswith("[x] "):
        pending.append(t)
print(pending)   # ['Call Anna', 'Pay bills']
Exercise 7. Given tasks = ["[x] Buy milk", "Call Anna", "[x] Wash car", "Pay bills"], build pending = the tasks not yet done → ['Call Anna', 'Pay bills'].
Exercise 8. Given the same tasks, count how many are done into done_count. Result 2.

7. A status summary

Finally, a one-line summary the app can show at the top: total, done, and pending counts, plus how far along you are as a percentage.

tasks = ["[x] Buy milk", "Call Anna", "[x] Wash car"]
total = len(tasks)
done = 0
for t in tasks:
    if t.startswith("[x] "):
        done += 1
percent = round(done / total * 100)
print(f"{done}/{total} done ({percent}%)")   # 2/3 done (67%)
Exercise 9. Given tasks = ["[x] Buy milk", "Call Anna", "[x] Wash car", "Pay bills"], build summary = "You have 4 tasks, 2 done, 2 pending" (use len, a loop, and an f-string).
Exercise 10. Given tasks = ["[x] Buy milk", "Call Anna", "[x] Wash car", "Pay bills"], compute the completion percent as a whole number: done ÷ total × 100, rounded. Here 2 / 4 × 100 = 50.

Recap of lesson 10: a small app is just simple operations on one data structure — here a list of task strings · add (skip blanks with .strip()) · list with i + 1 and a [x]/[ ] checkbox · mark done by adding the "[x] " tag (only once) · remove with pop(n - 1) · filter and count with a loop and startswith · summarise with an f-string and round.

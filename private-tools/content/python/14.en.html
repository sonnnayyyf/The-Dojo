Lesson 14 — Functions in depth: defaults, many returns, scope

You can now write and call functions. This lesson adds the three things that make them genuinely powerful in real code: default values (so some inputs are optional), returning more than one value at once, and understanding scope — which variables a function can see and which stay private inside it.

None of this is new syntax to memorise for its own sake. Each piece solves a real annoyance: default values save you from passing the same argument over and over; multiple returns let one function answer a richer question; and scope is the rule that keeps big programs from turning into a tangle of variables stepping on each other.

By the end you'll write functions that feel like the ones in real libraries — flexible, self-contained, and safe to reuse anywhere.

1. Default parameter values

Give a parameter a default with =. If the caller supplies that argument it's used; if not, the default kicks in. Optional inputs, for free.

def greet(name, greeting="Hello"):
    return f"{greeting}, {name}!"

print(greet("Anna"))            # Hello, Anna!   (default greeting)
print(greet("Ben", "Hi"))       # Hi, Ben!       (override it)
Exercise 1. Define greet with a second parameter greeting that defaults to "Hello", returning "greeting, name!". So greet("Anna") is "Hello, Anna!" and greet("Ben", "Hi") is "Hi, Ben!".
Exercise 2. Define power that takes base and exp (default 2) and returns base ** exp. So power(5) is 25 and power(2, 3) is 8.
Exercise 3. Define apply_discount that takes price and percent (default 10) and returns the price after taking off that percent. So apply_discount(100) is 90.0 and apply_discount(200, 25) is 150.0.

2. Returning several values

A function can hand back more than one value at once — just separate them with commas. Python bundles them into a tuple, and the caller can unpack them into separate names.

def first_last(items):
    return items[0], items[-1]

pair = first_last([10, 20, 30])
print(pair)                 # (10, 30)  — a tuple

lo, hi = first_last([10, 20, 30])   # unpack into two names
print(lo, hi)               # 10 30
Exercise 4. Define first_last that takes a list items and returns a tuple of its first and last element. So first_last([10, 20, 30]) is (10, 30).
Exercise 5. Define split_name that takes a full name like "Anna Bui" and returns a tuple (first, last) → ("Anna", "Bui"). (Use full.split().)
Exercise 6. Define high_low that takes a list of numbers nums and returns (smallest, largest) using a loop. So high_low([3, 1, 2]) is (1, 3).

3. Scope: what a function can see

Variables created inside a function are local — they exist only while the function runs and vanish when it returns. The outside program can't see them, and that's a good thing: it means a function's inner workings never accidentally clash with names elsewhere.

def make_label(n):
    tag = "item"          # local — only exists in here
    return f"{tag} {n}"

print(make_label(3))      # item 3
# print(tag)              # would be an ERROR: tag is not defined out here

Think of each function as a room with its own scratch paper. Whatever it scribbles (its local variables) is thrown away when it leaves the room; only what it returns comes out.

Exercise 7. Define make_label that takes n, uses a local variable tag = "item", and returns "item n". So make_label(3) is "item 3".

4. Functions that do real work

Put it together: parameters in, a loop or logic in the body, one clear value out.

def count_positive(nums):
    count = 0
    for n in nums:
        if n > 0:
            count += 1
    return count

print(count_positive([-1, 2, -3, 4]))   # 2
Exercise 8. Define count_positive that returns how many numbers in nums are greater than 0. So count_positive([-1, 2, -3, 4]) is 2.
Exercise 9. Define average that returns the average of a non-empty list nums (sum ÷ count). So average([2, 4, 6]) is 4.0.
🔥 Stretch (stats in one call). Define stats that takes a non-empty list nums and returns a tuple (count, total, average) using a loop. So stats([2, 4, 6]) is (3, 12, 4.0).
Recap of lesson 14: default values (def f(x, y=10):) make parameters optional · a function can return several values — Python bundles them into a tuple the caller can unpack (lo, hi = ...) · variables made inside a function are local and disappear when it returns — only the returned value escapes · combine parameters, loops and one clear return to build reliable little tools.

Bài 3 — Điều kiện: if / elif / else

Đến giờ chương trình của chúng ta chạy thẳng một mạch từ trên xuống. Nhưng phần mềm thật phải ra quyết định: đủ tuổi thì cho vào, sai mật khẩu thì báo lỗi, đơn từ 500k thì giảm giá. Bài này dạy máy tính chọn đường đi dựa trên điều kiện.

1. So sánh — nền tảng của mọi quyết định

Một phép so sánh luôn cho kết quả kiểu bool: True (đúng) hoặc False (sai).

print(7 > 3)      # True
print(7 < 3)      # False
print(5 == 5)     # True  — BANG NHAU? (hai sign bang)
print(5 != 4)     # True  — KHAC NHAU?
print(5 >= 5)     # True  — lon hon hoac bang
print(5 <= 4)     # False — nho hon hoac bang

Cực kỳ quan trọng: = là gán (bỏ giá trị vào biến), còn == là so sánh (hỏi có bằng nhau không). Nhầm hai cái này là lỗi kinh điển của người mới.

Bài tập 1. Cho a = 7 và b = 10. Tạo biến a_is_smaller = kết quả so sánh a có nhỏ hơn b hay không (kết quả là True/False).

2. if — làm gì đó KHI điều kiện đúng

Cấu trúc: từ khóa if, một điều kiện, dấu hai chấm :, rồi khối lệnh thụt vào bên dưới.

temperature = 39
if temperature > 37.5:
    print("Ban bi sot!")     # dong nay THUT VAO -> thuoc if
print("Da kiem tra xong")    # dong nay KHONG thut -> luon chay

Thụt lề (indentation) quyết định mọi thứ trong Python. Những dòng thụt vào cùng một mức tạo thành một khối chạy chung. Quy ước: thụt 4 dấu cách. Thụt sai → lỗi hoặc chạy sai ý.

Bài tập 2. Biến alert ban đầu là False. Nếu temperature lớn hơn 37.5 thì đổi alert thành True.

3. else — ngược lại thì làm gì

age = 15
if age >= 18:
    print("Duoc vao")
else:
    print("Chua du age")   # chay khi dieu kien if SAI
Bài tập 3. Cho score = 4. Tạo biến result = "Pass" nếu score >= 5, ngược lại là "Fail".

4. elif — nhiều nhánh

Khi có hơn hai trường hợp, dùng elif (viết tắt của "else if"). Python kiểm tra từ trên xuống và chạy nhánh ĐÚNG đầu tiên, rồi bỏ qua phần còn lại.

score = 7
if score >= 8:
    grade = "Excellent"
elif score >= 6.5:
    grade = "Good"
elif score >= 5:
    grade = "Average"
else:
    grade = "Weak"
print(grade)      # Kha
Bài tập 4. Cho score = 7. Tạo grade theo thang: >= 8 → "Excellent"; >= 6.5 → "Good"; >= 5 → "Average"; còn lại → "Weak".

5. Thứ tự các nhánh RẤT quan trọng

Vì Python dừng ở nhánh đúng đầu tiên, viết sai thứ tự sẽ cho kết quả sai. Ví dụ nếu để >= 5 lên trước >= 8, thì điểm 9 cũng bị xếp "Average" vì nó khớp >= 5 trước. Luôn xếp điều kiện chặt nhất (hẹp nhất) lên trên.

Bài tập 5. Cho age = 20. Tạo group: < 13 → "child"; < 20 → "teen"; còn lại → "adult".
Bài tập 6. Cho number = -4. Tạo sign: "positive" nếu number > 0; "negative" nếu number < 0; "zero" nếu bằng 0.

6. Dùng số dư % để kiểm tra chẵn/lẻ

Một số chẵn khi chia 2 dư 0. Vậy n % 2 == 0 nghĩa là "n chẵn".

n = 10
if n % 2 == 0:
    print("even")
else:
    print("odd")
Bài tập 7. Cho n = 7. Tạo kind = "even" nếu n chẵn, ngược lại "odd" (gợi ý: dùng % 2).
Bài tập 8. Cho hours = 14 (giờ trong ngày, 0–23). Tạo part_of_day: < 12 → "morning"; < 18 → "afternoon"; còn lại → "evening".

7. So sánh chuỗi & kiểm tra "thuộc về" (in)

Điều kiện không chỉ dùng cho số. Bạn có thể so sánh chuỗi bằng ==, và kiểm tra một giá trị có nằm trong một nhóm bằng in (danh sách [...] sẽ học kỹ ở bài 5).

role = "admin"
if role == "admin":
    print("Toan quyen")

day = "T7"
if day in ["T7", "CN"]:
    print("Cuoi tuan")
Bài tập 9. Cho day = "CN". Tạo is_weekend = True nếu day là "T7" hoặc "CN" (gợi ý: dùng day in ["T7", "CN"]).

8. Những lỗi thường gặp

  • Quên dấu hai chấm : sau điều kiện → lỗi cú pháp.
  • Quên thụt lề hoặc thụt không đều → lỗi IndentationError.
  • Dùng = thay vì == trong điều kiện → lỗi.
  • Xếp sai thứ tự elif → chương trình chạy nhưng cho kết quả sai (loại lỗi khó phát hiện nhất).
Ghi nhớ bài 3: so sánh cho True/False (== != < > <= >=) · if dieu_kien: + khối thụt lề chạy khi đúng · else cho trường hợp còn lại · elif cho nhiều nhánh, chạy nhánh đúng đầu tiên · thứ tự nhánh quan trọng · so sánh chuỗi & in · = gán ≠ == so sánh. Bài sau: kết hợp nhiều điều kiện (and/or/not) và điều kiện lồng nhau.
🔥 Thử thách (FizzBuzz). Cho n = 15. Tạo result: chia hết cho cả 3 và 5 → "FizzBuzz"; chỉ chia hết 3 → "Fizz"; chỉ chia hết 5 → "Buzz"; còn lại → chuỗi của số đó (str(n)). Nhớ: xét "cả 3 và 5" TRƯỚC.

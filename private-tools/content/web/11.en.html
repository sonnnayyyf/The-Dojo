Lesson 11 — Control flow & data

So far your code has run straight down, top to bottom. Real programs need to make decisions ("if the cart is empty, hide the checkout button") and repeat work ("for each product, draw a card"). Those two abilities — branching and looping — are called control flow, and they're what let a handful of lines handle a thousand items.

To do anything useful you also need to hold collections of data, not just single values. JavaScript gives you two everyday containers: the array — an ordered list like ["Mai", "Nam", "Lan"] — and the object — a labelled record like { name: "Mai", age: 20 }. Almost every app is arrays of objects: a list of products, a list of users, a list of messages.

This lesson combines the two ideas: store data in arrays and objects, then use if and loops to work through it. As before, console.log shows your results in the Output box. Let's teach your code to decide and repeat.

1. if / else — making decisions

An if runs a block only when its condition is true. Add else for the alternative. Conditions use comparisons: >, <, >=, <=, and === (equal).

let score = 75;
if (score >= 50) {
  console.log("Pass");
} else {
  console.log("Fail");
}

2. Arrays — ordered lists

An array holds many values in order, written in square brackets. Reach an item by its index (counting from 0): fruits[0] is the first. fruits.length is how many there are, and fruits.push(x) adds one to the end.

let fruits = ["apple", "banana", "cherry"];
console.log(fruits[0]);        // apple
console.log(fruits.length);    // 3
fruits.push("date");           // now 4 items

3. Loops — repeat without repeating yourself

A for loop repeats a block. The classic form counts: for (let i = 1; i <= 5; i++). To walk through an array's items, the cleaner for … of loop hands you each element in turn.

let sum = 0;
for (let i = 1; i <= 5; i++) {
  sum = sum + i;
}
console.log(sum);   // 15

for (let name of ["Mai", "Nam"]) {
  console.log(name);
}

4. Objects — labelled records

An object stores values under names (keys), in curly braces. Read a value with a dot: user.name. Objects are how you model a "thing" with several properties.

let user = { name: "Mai", age: 20 };
console.log(user.name);   // Mai
console.log(user.age);    // 20

Lesson 4 — CSS essentials & the box model

You can now structure a page — but everything looks like a 1994 document: black Times New Roman on white. CSS (Cascading Style Sheets) is the language that makes it look designed. Where HTML says what something is, CSS says how it should look: colour, size, spacing, borders, fonts. It's the single biggest lever you have over how professional a page feels.

CSS works by selecting elements and giving them declarations. Every rule has the same shape: a selector (which elements), then a block of property: value; pairs. h1 { color: teal; } means "find every <h1> and paint its text teal". You'll learn the three everyday selectors — by element, by class and by id — and the properties for colour and text.

Then comes the idea that unlocks all of layout: the box model. Every element is a rectangular box with four layers — content, padding, border and margin. Master those four and you control spacing everywhere. As always you'll edit real CSS in a live editor, pressing Run to watch the page restyle instantly.

1. The shape of a CSS rule

There are three selectors you'll use constantly: by element name (p — every paragraph), by class (.note — every element with class="note", reusable), and by id (#hero — the one element with id="hero", unique). A dot means class; a hash means id.

3. The box model

Every element is a box with four concentric layers, from the inside out: content (the text/image), padding (space inside the box, between content and border), border (the line around it), and margin (space outside, pushing other boxes away). Getting these right is 90% of good layout.

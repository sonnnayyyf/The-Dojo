Bài 11 — Luồng điều khiển & dữ liệu

Đến giờ code của bạn chạy thẳng một mạch, từ trên xuống. Chương trình thật cần ra quyết định ("nếu giỏ hàng rỗng thì ẩn nút thanh toán") và lặp lại công việc ("với mỗi sản phẩm, vẽ một thẻ"). Hai khả năng đó — rẽ nhánh và lặp — gọi là luồng điều khiển (control flow), và chúng cho phép vài dòng code xử lý cả nghìn mục.

Để làm được việc gì có ích, bạn cũng cần giữ các tập hợp dữ liệu, chứ không chỉ giá trị lẻ. JavaScript cho bạn hai hộp chứa thường ngày: mảng (array) — một danh sách có thứ tự như ["Mai", "Nam", "Lan"] — và đối tượng (object) — một bản ghi có nhãn như { name: "Mai", age: 20 }. Gần như mọi ứng dụng đều là mảng của các object: một danh sách sản phẩm, một danh sách người dùng, một danh sách tin nhắn.

Bài này kết hợp cả hai: lưu dữ liệu trong mảng và object, rồi dùng if và vòng lặp để xử lý nó. Như trước, console.log hiện kết quả trong ô Kết quả in ra. Dạy code của bạn biết quyết định và lặp nào.

1. if / else — ra quyết định

Một if chạy một khối chỉ khi điều kiện của nó là true. Thêm else cho trường hợp còn lại. Điều kiện dùng các phép so sánh: >, <, >=, <=, và === (bằng).

let score = 75;
if (score >= 50) {
  console.log("Pass");
} else {
  console.log("Fail");
}
Bài tập 1. ✍️ Đến lượt bạn. Biến score là 75. Viết một if / else console.log ra Pass khi score >= 50, ngược lại Fail.
Bài tập 2. ✍️ Đến lượt bạn. In một phép so sánh. console.log kết quả của 10 > 5 (phải in true).
Bài tập 3. Toán tử nào kiểm tra hai giá trị có bằng nhau không?
  1. =
  2. >
  3. ===
  4. =!

2. Mảng — danh sách có thứ tự

Một mảng giữ nhiều giá trị theo thứ tự, viết trong ngoặc vuông. Lấy một mục bằng chỉ số (index) (đếm từ 0): fruits[0] là cái đầu. fruits.length là số lượng, và fruits.push(x) thêm một cái vào cuối.

let fruits = ["apple", "banana", "cherry"];
console.log(fruits[0]);        // apple
console.log(fruits.length);    // 3
fruits.push("date");           // giờ có 4 mục
Bài tập 4. ✍️ Đến lượt bạn. Tạo một mảng nums giữ 10, 20, 30, rồi console.log(nums.length) (phải in 3).
Bài tập 5. ✍️ Đến lượt bạn. In mục đầu tiên. Với mảng có sẵn, console.log phần tử ở chỉ số 0 (phải in red).
Bài tập 6. ✍️ Đến lượt bạn. Thêm một mục. push chuỗi blue vào mảng, rồi console.log(colors.length) (phải in 3).

3. Vòng lặp — lặp mà không lặp lại chính mình

Một vòng for lặp lại một khối. Dạng kinh điển đếm số: for (let i = 1; i <= 5; i++). Để duyệt các mục của mảng, vòng for … of gọn hơn trao cho bạn từng phần tử lần lượt.

let sum = 0;
for (let i = 1; i <= 5; i++) {
  sum = sum + i;
}
console.log(sum);   // 15

for (let name of ["Mai", "Nam"]) {
  console.log(name);
}
Bài tập 7. ✍️ Đến lượt bạn. Cộng từ 1 đến 5. Dùng một vòng for để dựng sum, rồi console.log(sum) (phải in 15).
Bài tập 8. ✍️ Đến lượt bạn. In từng tên. Dùng một vòng for … of để console.log mỗi tên trong mảng (mỗi tên một dòng).

4. Object — bản ghi có nhãn

Một object lưu các giá trị dưới các tên (key), trong ngoặc nhọn. Đọc một giá trị bằng dấu chấm: user.name. Object là cách bạn mô hình một "thứ" có nhiều thuộc tính.

let user = { name: "Mai", age: 20 };
console.log(user.name);   // Mai
console.log(user.age);    // 20
Bài tập 9. ✍️ Đến lượt bạn. Tạo một object book với key title đặt là Dune, rồi console.log(book.title) (phải in Dune).
Bài tập 10. ✍️ Đến lượt bạn. Hai thuộc tính. Tạo let car = { make: "Toyota", year: 2020 }; và in đúng Toyota 2020 bằng template literal.

Lesson 1 — How the web works

Every time you open a website — a news page, a shop, a video app — a lot happens in the half-second before it appears. Your device sends a request across the internet to another computer, that computer sends files back, and your browser turns those files into the page you see and touch. Before you write a single line of code, it pays to understand this journey. It's the mental model everything else in this course hangs on.

Here's the key idea we'll build on for sixteen lessons: a web page is made of three separate languages, each with one job. HTML is the structure — the headings, paragraphs, images and buttons (the "what"). CSS is the style — colours, spacing, fonts and layout (the "how it looks"). JavaScript is the behaviour — what happens when you click, type or scroll (the "what it does"). Same three languages power every website on earth, from a personal blog to a bank.

You won't just read about this — you'll build it. Most of this lesson is real editing: you'll change headings, recolour text, restyle backgrounds and assemble tiny pages in a live editor, pressing Run to see the website render and get graded instantly. There's no syntax to memorise yet; you edit what's given and watch it come alive. Getting it wrong is fine — you just try again until it passes.

1. The request–response journey

When you type an address (a URL) and press Enter, your browser (the client) sends a request to a server — a computer somewhere whose job is to hold and hand out web files. The server sends back a response: the page's files. This back-and-forth is the heartbeat of the web.

Exercise 1. In this journey, what does the server do?

  2. It stores the web files and sends them back when asked.
  3. It decides what colour the buttons are.
  4. It is the same thing as your browser.

2. Three languages, three jobs

The response is (mostly) three kinds of file, each with a single responsibility. Keep this table in your head — the whole course is organised around it. In the next sections you'll build a small page one layer at a time and feel the difference.

LanguageJobThink of a house
HTMLStructure — headings, text, images, buttonsthe walls & rooms
CSSStyle — colours, fonts, spacing, layoutthe paint & furniture
JavaScriptBehaviour — what happens on click/type/scrollthe electricity & plumbing

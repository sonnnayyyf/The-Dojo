Lesson 7 — CSS grid & responsive design

Flexbox is perfect for laying things out in one direction — a row or a column. But many designs are true grids: a photo gallery, a dashboard, a shop's product listing, all rows and columns at once. For that, CSS has a purpose-built tool: CSS Grid. You define the columns, drop your items in, and the browser places them into a neat matrix.

Grid works like flexbox: you set display: grid on a container, then describe the columns with grid-template-columns. The magic ingredient is the fraction unit fr, which splits leftover space into equal shares — 1fr 1fr 1fr gives three equal columns that stretch to fit any screen. Add gap for spacing, exactly like flexbox.

The other half of this lesson is responsive design — making one page look good on a phone and a laptop. The tool is the media query: a block of CSS that only applies below (or above) a chosen screen width, letting you collapse a three-column grid into a single column on narrow screens. You'll build grids live and watch them respond.

1. display: grid

Turn a container into a grid and give it columns. grid-template-columns: 1fr 1fr 1fr means "three equal columns". The children flow into the cells automatically, wrapping to new rows as needed.

2. Spacing and the fraction unit

The fr unit shares out space. 2fr 1fr makes the first column twice as wide as the second. gap adds even spacing between all cells — no margins needed.

4. Responsive design & media queries

A phone screen is narrow; a laptop is wide. Responsive design adapts the layout to fit. The core tool is the media query: @media (max-width: 600px) { … } — the rules inside only apply when the screen is 600px wide or less. A classic pattern: three columns normally, one column on phones.

5. Units: px, %, and rem

You've used px (fixed pixels). Two more matter: % sizes relative to the parent (a width: 50% box is half its container — naturally responsive), and rem scales with the base font size (great for text and spacing that adapt).

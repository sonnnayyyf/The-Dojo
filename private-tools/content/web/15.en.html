Lesson 15 — Forms, validation & fetch

Forms are how the web collects real information — a login, a sign-up, a search, a checkout. You already know how to build a form's HTML; now you'll make it work with JavaScript: catch the submit, read what was typed, and validate it (is the email filled in? is the password long enough?) before doing anything. Good validation is what separates a toy from a real product.

You'll also meet the two things that let a page talk to the outside world. JSON is the universal text format for data — every API on earth speaks it — and JavaScript can turn JSON text into objects (JSON.parse) and back (JSON.stringify). And fetch is the function that requests data from a server without reloading the page, the technique behind live search, feeds and "load more" buttons.

You'll wire up submit handlers, block empty forms with clear error messages, and turn JSON into a rendered list — exactly what a real app does with data it fetches. Let's handle some real input.

1. Handling form submit

When a form is submitted it tries to reload the page by default. In a JavaScript app you stop that with event.preventDefault(), then handle everything yourself in a submit listener.

let form = document.querySelector("form");
form.addEventListener("submit", function (e) {
  e.preventDefault();               // stop the reload
  document.querySelector("#out").textContent = "Submitted!";
});

3. JSON — the language of data

JSON is text that looks like JavaScript objects and arrays. JSON.parse(text) turns a JSON string into a real object you can read; JSON.stringify(obj) does the reverse. This is how data travels between apps and servers.

let text = '{"name":"Mai","age":20}';
let user = JSON.parse(text);
console.log(user.name);            // Mai
console.log(JSON.stringify(user)); // back to text

4. fetch — data from a server

To load data from an API without reloading, you use fetch(url). It returns a promise, so you chain .then() to handle the response when it arrives — first turning it into JSON, then using it:

fetch("https://api.example.com/books")
  .then(response => response.json())   // parse the JSON body
  .then(data => {
    console.log(data);                 // now use the data
  });

The data you get back is JSON — exactly what you practised parsing above. (This box can't reach the network, so real requests are a deployed-site thing, but the shape is always this.)

Lesson 13 — The DOM: select & change elements

Here's where JavaScript starts to feel magic: it can reach into a live page and change it — swap text, recolour a box, add elements, hide things — all after the page has loaded. The bridge that makes this possible is the DOM (Document Object Model): the browser turns your HTML into a tree of objects that JavaScript can read and rewrite.

Working with the DOM is always the same two-step dance: select the element you want, then change it. To select, you use document.querySelector("…") with a CSS selector — the exact same selectors you learned for CSS (h1, .box, #title). Once you have the element, you change its text (.textContent), its HTML (.innerHTML), its style (.style.color), or its classes (.classList).

This is the most visual lesson yet — every exercise renders your change live in the preview. You'll grab elements and rewrite them on the fly. Select, change, watch it happen.

3. Changing text and HTML

.textContent sets plain text. .innerHTML sets HTML — the browser parses it, so you can inject whole elements. Use textContent for words, innerHTML when you need tags.

Exercise 5. ✍️ Your turn. Inject HTML. Set the #box element's innerHTML to <h2>Hi</h2> — a real heading should appear inside it.

4. Changing style

Every element has a .style you can write to. The property names are the CSS ones in camelCase: .style.color, .style.backgroundColor, .style.fontSize.

Exercise 6. ✍️ Your turn. Recolour the heading. Set the <h1>'s .style.color to red.
Exercise 7. ✍️ Your turn. Set a background. Set the #panel element's .style.backgroundColor to gold.

5. Classes and attributes

Instead of setting many styles by hand, add a ready-made class with .classList.add("name"). And change any attribute with .setAttribute("attr", "value") — handy for an image's src or a link's href.

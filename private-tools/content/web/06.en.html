Lesson 6 — CSS positioning & moving things

Flexbox arranges boxes in tidy rows and columns — but sometimes you need to place something exactly: a "New!" badge pinned to the corner of a card, a header that stays glued to the top as you scroll, a notification dot floating over an icon. That's the job of the position property. It lets you lift an element out of the normal flow and move it precisely with top, right, bottom and left.

By default every element is position: static — it just sits where the flow puts it, and the offset properties do nothing. The magic starts when you change that. relative nudges an element from its normal spot; absolute pins it to a chosen container; fixed locks it to the screen; and sticky lets it scroll until it reaches an edge, then holds. When boxes overlap, z-index decides which one sits on top.

These effects are all about movement, so you'll watch every one happen live. Set a property, press Run, and see the box jump, pin or float into place. Let's move some things around.

1. relative — nudge from home

position: relative keeps an element in the flow but lets you shift it with top/left/right/bottom. top: 20px pushes it down 20px from where it would normally sit; left: 20px pushes it right.

2. absolute — pin to a container

position: absolute takes an element out of the flow and pins it to its nearest ancestor that has a position set (usually a relative parent). This is how you drop a badge into a corner: make the card relative, make the badge absolute, then push it with top: 0; right: 0.

3. z-index — who sits on top

When positioned boxes overlap, the one with the higher z-index wins and appears in front. It only works on elements that have a position other than static.

Exercise 7. Run — the gold box covers the teal one. Raise the teal box's z-index above 2 and Run to flip which is on top.

4. fixed & sticky — stay in view

position: fixed pins an element to the screen — it stays put even as the page scrolls (think of a top navbar that's always there). position: sticky is a hybrid: the element scrolls normally until it reaches a given offset (like top: 0), then "sticks" there.

Lesson 12 — JavaScript functions

As programs grow, you find yourself writing the same few lines again and again — format a price, greet a user, total a cart. A function is a named, reusable block of code: you write the steps once, give them a name, and then call that name whenever you need the work done. Functions are how real code stays short, organised and DRY (Don't Repeat Yourself).

A function has two superpowers. It can take inputs — called parameters — so the same function works on different data (greet("Mai") vs greet("Nam")). And it can hand back a result with return, so you can use the answer elsewhere (let tax = calcTax(price)). Inputs in, a value out — that's the whole idea.

You'll define functions and immediately call them, watching results in the Output box or on the page. Once you're comfortable here, the DOM lessons ahead become easy — they're just functions reacting to the user. Let's build reusable code.

1. Defining and calling a function

Write function name() { … } to define it, then name() to call (run) it. Defining a function doesn't run it — calling does.

function sayHi() {
  console.log("Hi there!");
}
sayHi();   // runs it → prints Hi there!

2. Parameters — inputs

Put names in the parentheses to accept inputs. Inside the function, those names hold whatever you pass when you call it.

function greet(name) {
  console.log("Hello, " + name);
}
greet("Mai");   // Hello, Mai
greet("Nam");   // Hello, Nam

3. return — handing back a value

Most functions compute something rather than print it. Use return to send a value back to whoever called the function, so you can store or reuse it.

function double(n) {
  return n * 2;
}
let result = double(5);
console.log(result);   // 10

4. Arrow functions — a shorter form

Modern JavaScript has a compact way to write small functions: the arrow function. const square = (n) => n * n; means the same as a function that returns n * n. You'll see this shorthand everywhere.

const square = (n) => n * n;
console.log(square(4));   // 16

Bài 12 — Hàm trong JavaScript

Khi chương trình lớn dần, bạn thấy mình viết đi viết lại cùng vài dòng — định dạng một mức giá, chào một người dùng, tính tổng giỏ hàng. Một hàm (function) là một khối code có tên, dùng lại được: bạn viết các bước một lần, đặt cho nó một cái tên, rồi gọi tên đó bất cứ khi nào cần làm việc đó. Hàm là cách code thật giữ được ngắn gọn, có tổ chức và DRY (Đừng Lặp Lại Chính Mình).

Một hàm có hai sức mạnh. Nó có thể nhận đầu vào — gọi là tham số (parameter) — để cùng một hàm làm việc trên dữ liệu khác nhau (greet("Mai") so với greet("Nam")). Và nó có thể trả lại một kết quả bằng return, để bạn dùng câu trả lời ở nơi khác (let tax = calcTax(price)). Đầu vào vào, một giá trị ra — đó là toàn bộ ý tưởng.

Bạn sẽ định nghĩa hàm và gọi chúng ngay, xem kết quả trong ô Kết quả in ra hoặc trên trang. Khi đã quen ở đây, các bài DOM phía trước trở nên dễ — chúng chỉ là các hàm phản ứng với người dùng. Dựng code dùng lại được nào.

1. Định nghĩa và gọi một hàm

Viết function name() { … } để định nghĩa nó, rồi name() để gọi (chạy) nó. Định nghĩa một hàm không chạy nó — gọi mới chạy.

function sayHi() {
  console.log("Hi there!");
}
sayHi();   // chạy nó → in Hi there!
Bài tập 1. ✍️ Đến lượt bạn. Định nghĩa một hàm greet console.log ra Hello!, rồi gọi nó.

2. Tham số — đầu vào

Đặt các tên trong ngoặc đơn để nhận đầu vào. Bên trong hàm, các tên đó giữ bất cứ gì bạn truyền vào khi gọi.

function greet(name) {
  console.log("Hello, " + name);
}
greet("Mai");   // Hello, Mai
greet("Nam");   // Hello, Nam
Bài tập 2. ✍️ Đến lượt bạn. Định nghĩa greet(name) console.log ra Hello, theo sau là tên, rồi gọi greet("Dojo") (phải in Hello, Dojo).

3. return — trả lại một giá trị

Phần lớn hàm tính ra thứ gì đó chứ không in nó. Dùng return để gửi một giá trị về cho nơi đã gọi hàm, để bạn lưu hoặc dùng lại.

function double(n) {
  return n * 2;
}
let result = double(5);
console.log(result);   // 10
Bài tập 3. Từ khóa nào gửi một giá trị về từ một hàm đến nơi nó được gọi?
  1. log
  2. function
  3. return
  4. let
Bài tập 4. ✍️ Đến lượt bạn. Định nghĩa double(n) trả về n * 2. (Đừng log — chỉ return.)
Bài tập 5. ✍️ Đến lượt bạn. Định nghĩa add(a, b) trả về tổng a + b.
Bài tập 6. ✍️ Đến lượt bạn. Định nghĩa welcome(name) trả về chuỗi Hello, + name + ! (ví dụ welcome("Mai") trả về Hello, Mai!). Template literal là dễ nhất.

4. Arrow function — dạng ngắn hơn

JavaScript hiện đại có cách viết gọn cho các hàm nhỏ: arrow function. const square = (n) => n * n; nghĩa giống một function trả về n * n. Bạn sẽ thấy cách viết tắt này ở khắp nơi.

const square = (n) => n * n;
console.log(square(4));   // 16
Bài tập 7. ✍️ Đến lượt bạn. Viết một arrow function triple trả về n * 3 (dùng const triple = (n) => …).

5. Hàm biết quyết định

Kết hợp một hàm với một if (hoặc một phép so sánh) để trả lời câu hỏi có/không.

Bài tập 8. ✍️ Đến lượt bạn. Định nghĩa isAdult(age) trả về true khi age >= 18, ngược lại false. (Mẹo: return age >= 18; chạy trực tiếp.)
Bài tập 9. ✍️ Đến lượt bạn. Định nghĩa total(prices) nhận một mảng số, lặp qua nó, và trả về tổng của chúng. (ví dụ total([10, 20, 30]) trả về 60.)

6. Hàm cập nhật trang

Bài tập 10. ✍️ Đến lượt bạn. Định nghĩa show(msg) gán document.body.textContent thành msg. Rồi gọi show("Done!") — bạn sẽ thấy nó trong ô xem trước.
Bài tập 11. ✍️ Đến lượt bạn. Định nghĩa price(item, cost) trả về một chuỗi như Coffee: 25000. Rồi gọi nó và gán document.body.textContent thành price("Coffee", 25000).
Bài tập 12. 🔥 Nâng cao — ✍️ đến lượt bạn. Định nghĩa makeCard(title, author) trả về một chuỗi HTML <h3>title</h3><p>author</p> (với các giá trị điền vào). Rồi gán document.body.innerHTML thành makeCard("Dune", "Herbert") — một thẻ thật hiện ra.

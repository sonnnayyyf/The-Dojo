Lesson 8 — CSS transitions, transforms & animations

Static pages are fine, but the web feels alive because things move: a button that gently grows when you hover, a card that lifts on tap, a loading spinner that turns, a notification that slides in. These little touches make an interface feel polished and responsive to the user. The best part — they're pure CSS. No JavaScript required.

Three tools give you all of it. transform moves, rotates or scales an element without disturbing the layout around it. transition makes a change happen smoothly over time instead of snapping — the single most useful "make it feel nice" property. And @keyframes + animation let you script a repeating, multi-step motion like a spinner or a pulse.

Motion is impossible to appreciate on paper, so every example here is live. Run them, hover over the previews, and tweak the numbers to feel how duration and scale change the mood. Let's make things move.

1. transform — move, rotate, scale

transform visually changes an element: rotate(20deg) tilts it, scale(1.5) makes it 1.5× bigger, translate(10px, 0) shifts it. Crucially, it doesn't push other elements around — it's a purely visual effect, perfect for hover and animation.

2. transition — smooth, not sudden

By default a style change is instant. transition spreads it over time. transition: all 0.3s means "animate any change to this element over 0.3 seconds". Pair it with a :hover rule — the hover state defines the end look, and the transition makes getting there smooth.

3. Hover effects

The :hover pseudo-class targets an element only while the mouse is over it. Combine transition (on the base rule) with a change (on the :hover rule) for a classic interactive button.

Exercise 7. Run, then hover the button — it changes colour smoothly. Try changing the hover colour.

4. @keyframes & animation

For motion that runs on its own (a spinner, a pulse), define the steps with @keyframes name { from { … } to { … } }, then attach it with animation: name duration timing repeat. For example animation: spin 2s linear infinite runs the spin keyframes forever, 2 seconds per loop.

Lesson 5 — CSS layout with flexbox

Everything you've styled so far has stacked top to bottom, one block under the last. But real interfaces put things side by side: a logo on the left and a menu on the right, a row of product cards, buttons in a toolbar. For decades this was the hardest part of CSS. Then flexbox arrived and made it easy — it is the layout tool you'll reach for every single day.

The idea is simple: pick a container and set display: flex. Instantly its direct children line up in a row, and you gain a set of controls to distribute and align them. Two properties do most of the work: justify-content spaces the items along the main axis (by default, left↔right), and align-items aligns them across the cross axis (top↔bottom). Add gap for even spacing between them.

Because flexbox is visual, you learn it by seeing it move. Every exercise here is a live preview: change one property, press Run, and watch the boxes slide into place. Let's lay things out.

1. display: flex — from stack to row

By default, block elements stack vertically. Turn their parent into a flex container and the children snap into a horizontal row.

Exercise 1. Run it once (stacked). Then change display: block to display: flex and Run again — the boxes line up in a row.

2. justify-content — spacing along the row

On a flex container, justify-content controls how items sit along the main (horizontal) axis: flex-start (default, left), center, flex-end (right), space-between (push to the edges, gaps between), and space-around.

Exercise 3. Run, then try each value of justify-content and watch the three boxes shift.

3. align-items — the cross axis

While justify-content works along the row, align-items aligns items across it (vertically, when the row is horizontal): flex-start (top), center, flex-end (bottom), stretch. Setting both to center is the classic way to perfectly centre something.

Exercise 7. Run — the boxes sit centred in a tall row. Change align-items to flex-start and Run to see them jump to the top.

4. gap and flex-direction

gap adds even spacing between flex items — cleaner than margins. And flex-direction: column flips the main axis to vertical, so items stack (but with all the flex controls still available).

Lesson 10 — JavaScript basics

You can now build and style pages — but they just sit there. JavaScript is the language that makes a page think and react: remember values, do calculations, respond to clicks, update the screen. It's the third and final layer of the web, and the one that turns a poster into an app. Welcome to the second half of the course.

Every program, in any language, is built from the same tiny bricks: values (a piece of text, a number), variables (named boxes that store those values), and operators (math and comparisons). Master those and everything else — loops, functions, whole apps — is just combinations of them. JavaScript is a friendly place to learn them because it runs everywhere and shows results instantly.

Your new best friend is console.log() — it prints a value so you can see what your code is doing. In these exercises, whatever you console.log shows up in the Output box when you press Run. Type code, run it, read the output, get graded. Let's write some JavaScript.

1. console.log — see your code think

console.log(x) prints x so you can inspect it. It's how every developer checks their work. Text (a string) goes in quotes; numbers don't.

Exercise 1. ✍️ Your turn. Print a greeting. Use console.log to print exactly Hello, Dojo! (in quotes).

2. Variables — named boxes

A variable stores a value under a name so you can reuse it. Declare one with let (a value that can change) or const (one that won't). Then use the name anywhere.

let city = "Hanoi";
console.log(city);
Exercise 2. ✍️ Your turn. Create a variable city holding the string Hanoi, then console.log(city).
Exercise 3. ✍️ Your turn. Store a number. Create const age = 20; then print it with console.log(age).

3. Data types — text, numbers, true/false

Three basic types cover most of what you store: a string (text in quotes, "hi"), a number (42, no quotes), and a boolean (true or false). The typeof operator tells you which one a value is.

console.log(typeof "hi");    // string
console.log(typeof 42);      // number
console.log(typeof true);    // boolean

4. Operators — doing maths

The usual arithmetic works: + add, - subtract, * multiply, / divide. You can compute right inside console.log, or store the result in a variable.

console.log(5 + 3);      // 8
console.log(10 * 2);     // 20
let total = 4 + 6;
console.log(total);      // 10
Exercise 6. ✍️ Your turn. Print the result of 7 * 6 using console.log (the answer should print as 42).
Exercise 7. ✍️ Your turn. Store a sum. Create let price = 25000; and let qty = 3;, then console.log(price * qty) (should print 75000).

5. Template literals — put values into text

To build a sentence with variables inside, use a template literal: backticks `…` with ${…} holes. `Hi ${name}` drops the value of name into the string.

let name = "Mai";
console.log(`Hello, ${name}!`);   // Hello, Mai!
Exercise 8. ✍️ Your turn. Create let name = "Mai"; then use a template literal to print exactly Hello, Mai!
Exercise 9. ✍️ Your turn. Combine data. Create let item = "Coffee"; and let cost = 25000;, then print exactly Coffee costs 25000 using a template literal.

6. Show a result on the page

Console output is for you, the developer. To show something to the user, put it on the page — the simplest way is document.body.textContent = …. (Next lessons go much deeper into this.)

Exercise 10. ✍️ Your turn. Put text on the page. Set document.body.textContent to Welcome! — you'll see it appear in the preview.
Exercise 11. ✍️ Your turn. Compute then show. Create let a = 8; and let b = 5;, then set document.body.textContent to the string Sum: 13 using a template literal with ${a + b}.
Exercise 12. 🔥 Stretch — ✍️ your turn. Build a tiny receipt. Create let item = "Tea";, let price = 30000;, let qty = 2;. console.log exactly Tea x2, and set document.body.textContent to Total: 60000 (use price * qty).

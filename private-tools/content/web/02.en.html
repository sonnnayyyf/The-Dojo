Lesson 2 — HTML essentials

In Lesson 1 you saw that HTML is the structure of a page — the walls and rooms. Now we build those walls properly. HTML stands for HyperText Markup Language, and the word "markup" is the key: you take plain text and mark it up by wrapping pieces in tags that tell the browser what each piece is — "this is a heading", "this is a paragraph", "this is a link". The browser reads those tags and renders the page accordingly.

Almost everything in HTML follows one simple shape: an opening tag, some content, and a matching closing tag — for example <p>Hello</p>. That trio is called an element. Learn to read that shape and HTML stops looking like a wall of angle brackets and starts looking like a set of labelled boxes. In this lesson you'll meet the handful of elements every single web page uses: headings, paragraphs, emphasis, links and images.

As always, you'll spend most of your time building. You'll add headings, write paragraphs, make words bold, create real clickable links and drop in images — pressing Run to watch each one appear and getting graded instantly. Type it, run it, see it. Let's mark some things up.

1. The anatomy of an element

Every element is a tag pair wrapped around content. The opening tag names the element; the closing tag is the same name with a /. Whatever sits between them is the element's content.

2. Headings and paragraphs

The two workhorses of any page are headings and paragraphs. HTML gives you six heading levels, <h1> (biggest, most important) down to <h6> (smallest). Use one <h1> for the page's main title, then <h2> for section titles, and so on. Body text goes in paragraphs, <p>…</p>.

3. Emphasis: bold and italic

To stress words inside text, wrap them in <strong> (important — shows bold) or <em> (emphasis — shows italic). These sit inside a paragraph, around just the words you want to mark.

4. Links — the "hypertext" in HTML

A link is what makes the web a web. You create one with the anchor element <a>, and you tell it where to go with an attribute called href. An attribute is extra information written inside the opening tag, as name="value". The clickable text goes between the tags.

5. Images

Images use the <img> element. It's unusual in two ways: it has no closing tag (the content is the file), and it needs two attributes — src (the image file to show) and alt (a short text description, read aloud to blind users and shown if the image fails to load). Always write an alt.

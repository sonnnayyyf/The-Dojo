Lesson 16 — Capstone: build your own interactive web app

This is it — the finish line. Over fifteen lessons you learned to structure pages with HTML, style and lay them out with CSS, and bring them to life with JavaScript: variables, arrays, functions, the DOM, events, forms. A capstone is where those separate skills fuse into one real thing you built yourself, from an empty file to a working app. It's the project you'll show people.

To get you there, most of this lesson is a guided build of a classic interactive app — a Task Manager — one feature at a time, each graded live: render a list from data, add items on a button click, validate a form, mark things done, delete them, and keep a live count. By the end you'll have practised every moving part of a small app. Then you'll build your own capstone from three project options and submit it.

Unlike earlier lessons, your final capstone is built in VS Code (real files, like a real developer) and submitted to your teacher as a code file plus a screenshot. The in-browser exercises below are your training reps; the project brief at the bottom is the real deliverable. Let's build something you're proud of.

1. Render a list from data

Almost every app turns data into DOM. Loop over an array and build the HTML. This is the heart of a task list, a feed, a product grid.

let tasks = ["Buy milk", "Call Mai"];
let html = "";
for (let t of tasks) { html += "<li>" + t + "</li>"; }
document.querySelector("#list").innerHTML = html;
Exercise 1. ✍️ Your turn. Render the tasks. Loop over the tasks array and fill #list with one <li> per task (three items should appear).

🏠 Your Capstone — build it in VS Code & submit

Now build your own app from scratch in VS Code and submit it. Pick one project below (or invent your own of similar scope). Build it as real files, then send your teacher (1) your code and (2) a screenshot of it running in the browser.

Choose one project:

ProjectWhat it doesMust use
Task ManagerAdd tasks, mark them done, delete them, show a live count.form + validation, add/delete on events, render a list, a live counter
Quiz appShow questions with options; the user picks answers and sees a final score.data in an array of objects, click events, score counter, show result at the end
Photo / product galleryA responsive grid of cards; a search or filter box narrows what's shown.CSS grid, an array of items rendered to the DOM, an input event that filters

Requirements (every project):

  1. A proper document skeleton: <!doctype html>, <head> with a <title>, and a linked style.css.
  2. Semantic structure — a <header>, <main>, and <footer>.
  3. Styled with CSS you wrote: colours, spacing, and a flexbox or grid layout.
  4. At least one event (click, submit or input) that changes the page via JavaScript.
  5. Data held in an array and rendered to the DOM with a loop.
  6. One nice touch: a hover effect, a transition, or an empty-state message.

How to build & submit:

  1. In VS Code, create a project folder with index.html, style.css and script.js (link the CSS in the head and the JS before </body>).
  2. Build it step by step — structure first, then style, then behaviour — testing in the browser as you go (double-click index.html to open it).
  3. When it works, take a screenshot of it running.
  4. Send your teacher the code (the three files) and the screenshot on Zalo. Use the 🥋 Ask teacher button on any exercise if you get stuck.

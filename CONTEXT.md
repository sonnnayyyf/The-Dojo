# Dojo Platform & Curriculum Context

## Business Model
- Hybrid model: Self-paced 20-lesson interactive web course + 1-on-1 private tutoring.
- Access system: Single-use unique entitlement codes unlock paid course modules upon purchase.
- Delivery style: In-browser interactive execution (LeetCode-style with automated assertions).

## Python Fundamental Course Structure (40 Hours / 20 Lessons)
- Target Audience: Total beginners (standard pacing).
- Core Modules:
  - Module 1 (L1–L5): Basics, Branching (if/elif/else hit in L2), while loops, sentinel retries, range-based for loops.
  - Module 2 (L6–L10): Lists, direct iteration, index loops, nested grid loops, sequence practice.
  - Module 3 (L11–L15): Dictionaries, Tuples/Sets, nested JSON-like structures.
  - Module 4 (L16–L20): Functions, scope, exception handling, File I/O (CSV/Text), Capstone App.

## Lesson Format
- Each lesson includes: Concept explanations, worked examples, and auto-graded practical exercises (running in-browser via Pyodide/JS test runners).
